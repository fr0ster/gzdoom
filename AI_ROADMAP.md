# 🤖 AI GZDoom Project Roadmap

## 📋 Поточний стан проекту (Липень 2025)

### ✅ Завершені компоненти
- **Базова AI архітектура** - система конфігурації та управління
- **Sight System** - відстеження видимих об'єктів в реальному часі
- **Monster Tracking** - аналіз монстрів (здоров'я, швидкість, поведінка)
- **MCP Integration** - протокол для зовнішніх AI систем
- **Game Loop Integration** - інтеграція в основний цикл GZDoom
- **Build System** - успішна збірка та встановлення в ~/opt/doom
- **Launch Scripts** - автоматизовані скрипти запуску з правильними залежностями

### 🏗️ Поточна архітектура
```
src/playsim/
├── ai_config.cpp/h     # Конфігурація AI системи
├── p_sightinfo.cpp/h   # Відстеження об'єктів
└── d_player.h          # Розширення структури гравця

src/d_main.cpp          # Інтеграція в головний цикл
```

### ⚙️ Конфігурація системи
- **Частота оновлення**: 0.1 секунди (10 FPS)
- **Максимум монстрів**: 10 одночасно
- **Радіус сканування**: 1000 одиниць
- **MCP сервер**: localhost:12345
- **Debug режим**: доступний

- [ ] **Performance benchmarks**
  - Вимірювання впливу на FPS
