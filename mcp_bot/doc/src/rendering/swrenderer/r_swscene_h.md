# r_swscene.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із представленням сцени у software-рендері.

## Короткий опис
Оголошує основні структури для зберігання інформації про сцену, її елементи, параметри рендерингу, а також функції для роботи зі сценою.

## Основні сутності
- Структури для представлення сцени, її елементів, параметрів.
- Оголошення функцій для ініціалізації, оновлення, очищення сцени.

## Зв'язки з іншими модулями
Використовується software-рендером для організації рендерингу сцени, взаємодіє з геометрією, буферами, менеджером текстур.
