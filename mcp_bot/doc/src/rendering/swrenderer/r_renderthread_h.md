# r_renderthread.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із багатопотоковим рендерингом у software-рендері.

## Короткий опис
Оголошує структури та функції для організації рендерингу у окремому потоці, синхронізації, передачі даних між потоками, оптимізації продуктивності.

## Основні сутності
- Структури для представлення потоку рендерингу, задач, черг.
- Оголошення функцій для запуску, зупинки, синхронізації рендер-потоку.

## Зв'язки з іншими модулями
Використовується software-рендером для оптимізації рендерингу, взаємодіє з основним рендерером, менеджером ресурсів, буферами.
