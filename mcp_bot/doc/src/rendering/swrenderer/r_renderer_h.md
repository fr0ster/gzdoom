# r_renderer.h

## Призначення файлу
Заголовочний файл для оголошення інтерфейсів та структур, пов'язаних із рендерером у software-рендері.

## Короткий опис
Оголошує основні інтерфейси, абстрактні класи, структури для організації рендерингу, взаємодії з буферами, текстурами, освітленням.

## Основні сутності
- Інтерфейси та абстрактні класи для рендерера.
- Оголошення функцій для ініціалізації, рендерингу, управління ресурсами.

## Зв'язки з іншими модулями
Використовується software-рендером для організації рендерингу, взаємодіє з геометрією, менеджером текстур, буферами, освітленням.
