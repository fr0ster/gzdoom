# r_swrenderer.cpp

## Призначення файлу
Файл реалізує основні функції software-рендера: ініціалізація, рендеринг кадру, управління ресурсами, очищення.

## Короткий опис
Містить реалізацію головного класу рендерера, функцій для підготовки сцени, рендерингу, управління буферами, текстурами, освітленням. Забезпечує інтеграцію рендерера з іншими підсистемами рушія.

## Основні сутності
- Головний клас software-рендера.
- Функції для ініціалізації, рендерингу, очищення, управління ресурсами.

## Зв'язки з іншими модулями
Використовується рушієм гри для рендерингу у програмному режимі, взаємодіє з геометрією, менеджером текстур, буферами, освітленням.
