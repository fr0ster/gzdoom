# r_wallsprite.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із спрайтами на стінах у software-рендері.

## Короткий опис
Оголошує структури та функції для представлення, підготовки та рендерингу спрайтів, які розміщуються на стінах (наприклад, декалі, графіті, ефекти).

## Основні сутності
- Структури для представлення спрайтів на стінах.
- Оголошення функцій для рендерингу, оновлення, взаємодії з геометрією стін.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу спрайтів на стінах, взаємодіє з геометрією, менеджером текстур, буферами.
