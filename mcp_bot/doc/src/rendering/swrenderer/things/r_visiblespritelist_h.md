# r_visiblespritelist.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних зі списком видимих спрайтів у software-рендері.

## Короткий опис
Оголошує структури та функції для зберігання, оновлення та обробки списку спрайтів, які мають бути відрендерені у поточному кадрі.

## Основні сутності
- Структури для представлення списку видимих спрайтів.
- Оголошення функцій для додавання, видалення, оновлення спрайтів у списку.

## Зв'язки з іншими модулями
Використовується software-рендерером для організації рендерингу спрайтів, взаємодіє з менеджером текстур, геометрією, буферами.
