# r_wallsprite.cpp

## Призначення файлу
Файл реалізує функції для роботи зі спрайтами на стінах у software-рендері: підготовка, рендеринг, оновлення.

## Короткий опис
Містить реалізацію структур і функцій для представлення, підготовки та рендерингу спрайтів, які розміщуються на стінах (наприклад, декалі, графіті, ефекти). Забезпечує коректне відображення спрайтів на стінах у сцені.

## Основні сутності
- Функції для рендерингу, оновлення, взаємодії з геометрією стін.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу спрайтів на стінах, взаємодіє з геометрією, менеджером текстур, буферами.
