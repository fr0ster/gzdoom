# r_particle.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із частинками у software-рендері.

## Короткий опис
Оголошує класи та функції для створення, оновлення та рендерингу частинок (диму, іскор, ефектів) у сцені.

## Основні сутності
- Оголошення класів і структур для представлення частинок.
- Оголошення функцій для керування життєвим циклом та рендерингом частинок.

## Зв'язки з іншими модулями
Використовується рендерером для візуалізації ефектів, взаємодіє з іншими об'єктами сцени, менеджером текстур та освітленням.
