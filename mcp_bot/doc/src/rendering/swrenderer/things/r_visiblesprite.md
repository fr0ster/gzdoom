# r_visiblesprite.cpp

## Призначення файлу
Файл реалізує функції для роботи з окремим видимим спрайтом у software-рендері: ініціалізація, оновлення, використання параметрів.

## Короткий опис
Містить реалізацію структур і функцій для зберігання параметрів окремого спрайта, який має бути відрендерений у поточному кадрі, та роботи з цими параметрами. Забезпечує коректне відображення спрайтів у сцені.

## Основні сутності
- Функції для ініціалізації, оновлення, використання параметрів спрайта.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу спрайтів, взаємодіє зі списком видимих спрайтів, менеджером текстур, буферами.
