# r_sprite.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із спрайтами у software-рендері.

## Короткий опис
Оголошує структури та функції для представлення, підготовки та рендерингу спрайтів у сцені.

## Основні сутності
- Структури для представлення спрайтів.
- Оголошення функцій для рендерингу, оновлення, взаємодії з іншими об'єктами сцени.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу спрайтів, взаємодіє з геометрією, менеджером текстур, буферами.
