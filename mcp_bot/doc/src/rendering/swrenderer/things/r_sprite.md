# r_sprite.cpp

## Призначення файлу
Файл реалізує функції для роботи зі спрайтами у software-рендері: підготовка, рендеринг, оновлення.

## Короткий опис
Містить реалізацію структур і функцій для представлення, підготовки та рендерингу спрайтів у сцені. Забезпечує коректне відображення спрайтів у сцені.

## Основні сутності
- Функції для рендерингу, оновлення, взаємодії з іншими об'єктами сцени.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу спрайтів, взаємодіє з геометрією, менеджером текстур, буферами.
