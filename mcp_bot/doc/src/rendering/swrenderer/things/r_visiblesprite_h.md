# r_visiblesprite.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із представленням окремого видимого спрайта у software-рендері.

## Короткий опис
Оголошує структури для зберігання параметрів окремого спрайта, який має бути відрендерений у поточному кадрі, та функції для роботи з цими параметрами.

## Основні сутності
- Структури для представлення видимого спрайта.
- Оголошення функцій для ініціалізації, оновлення, використання параметрів спрайта.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу спрайтів, взаємодіє зі списком видимих спрайтів, менеджером текстур, буферами.
