# r_visiblespritelist.cpp

## Призначення файлу
Файл реалізує функції для роботи зі списком видимих спрайтів у software-рендері: додавання, видалення, оновлення, обробка.

## Короткий опис
Містить реалізацію структур і функцій для зберігання, оновлення та обробки списку спрайтів, які мають бути відрендерені у поточному кадрі. Забезпечує коректну організацію рендерингу спрайтів.

## Основні сутності
- Функції для додавання, видалення, оновлення спрайтів у списку.

## Зв'язки з іншими модулями
Використовується software-рендерером для організації рендерингу спрайтів, взаємодіє з менеджером текстур, геометрією, буферами.
