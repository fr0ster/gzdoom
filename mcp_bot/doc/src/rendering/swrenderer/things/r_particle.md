# r_particle.cpp

## Призначення файлу
Реалізація рендерингу частинок у software-рендері.

## Короткий опис
Містить функції та класи для відображення частинок (наприклад, диму, іскор, ефектів) у сцені. Забезпечує обробку позицій, кольорів, прозорості та взаємодію з іншими об'єктами.

## Основні сутності
- Класи та функції для створення, оновлення та рендерингу частинок.
- Обробка властивостей частинок: позиція, колір, прозорість, життєвий цикл.

## Зв'язки з іншими модулями
Використовується підсистемою рендерингу для візуалізації ефектів, взаємодіє з менеджером текстур, освітленням, viewport та іншими об'єктами сцени.
