# r_decal.cpp

## Призначення файлу
Реалізація рендерингу декалей у software-рендері.

## Короткий опис
Містить функції та класи для відображення декалей (слідів, плям, написів) на поверхнях у сцені. Забезпечує обробку позицій, орієнтації, прозорості та взаємодію з геометрією рівня.

## Основні сутності
- Класи та функції для створення, оновлення та рендерингу декалей.
- Обробка властивостей: позиція, орієнтація, прозорість, тип поверхні.

## Зв'язки з іншими модулями
Використовується рендерером для візуалізації слідів та ефектів на поверхнях, взаємодіє з геометрією рівня, менеджером текстур, освітленням.
