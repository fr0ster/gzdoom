# r_playersprite.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із спрайтами гравця у software-рендері.

## Короткий опис
Оголошує структури та функції для представлення, підготовки та рендерингу спрайтів, які відображаються від імені гравця (наприклад, зброя, руки) у сцені.

## Основні сутності
- Структури для представлення спрайтів гравця.
- Оголошення функцій для рендерингу, оновлення, взаємодії з іншими об'єктами сцени.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу спрайтів гравця, взаємодіє з геометрією, менеджером текстур, буферами.
