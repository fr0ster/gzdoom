# r_voxel.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із вокселями у software-рендері.

## Короткий опис
Оголошує структури та функції для представлення, підготовки та рендерингу воксельних об'єктів (3D-піксельна графіка) у сцені.

## Основні сутності
- Структури для представлення вокселів.
- Оголошення функцій для рендерингу, оновлення, взаємодії з іншими об'єктами сцени.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу воксельних об'єктів, взаємодіє з геометрією, менеджером текстур, буферами.
