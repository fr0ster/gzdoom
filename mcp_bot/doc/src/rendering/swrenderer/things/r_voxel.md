# r_voxel.cpp

## Призначення файлу
Файл реалізує функції для роботи з вокселями у software-рендері: підготовка, рендеринг, оновлення.

## Короткий опис
Містить реалізацію структур і функцій для представлення, підготовки та рендерингу воксельних об'єктів (3D-піксельна графіка) у сцені. Забезпечує коректне відображення вокселів у сцені.

## Основні сутності
- Функції для рендерингу, оновлення, взаємодії з іншими об'єктами сцени.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу воксельних об'єктів, взаємодіє з геометрією, менеджером текстур, буферами.
