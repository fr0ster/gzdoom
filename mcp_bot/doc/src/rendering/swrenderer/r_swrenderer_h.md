# r_swrenderer.h

## Призначення файлу
Головний заголовочний файл для software-рендера. Оголошує основні класи, структури та функції для організації рендерингу у програмному режимі.

## Короткий опис
Містить оголошення основних класів рендерера, інтерфейсів для ініціалізації, рендерингу кадру, управління буферами, текстурами, освітленням.

## Основні сутності
- Головний клас software-рендера.
- Оголошення функцій для ініціалізації, рендерингу, очищення, управління ресурсами.

## Зв'язки з іншими модулями
Використовується рушієм гри для рендерингу у програмному режимі, взаємодіє з геометрією, менеджером текстур, буферами, освітленням.
