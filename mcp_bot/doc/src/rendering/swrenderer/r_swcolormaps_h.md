# r_swcolormaps.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із colormaps (картами кольорів) у software-рендері.

## Короткий опис
Оголошує структури для зберігання та обробки colormaps, а також функції для їх ініціалізації, оновлення, використання під час рендерингу.

## Основні сутності
- Структури для представлення colormaps.
- Оголошення функцій для ініціалізації, оновлення, використання colormaps.

## Зв'язки з іншими модулями
Використовується software-рендером для обробки кольорів, взаємодіє з менеджером текстур, буферами, освітленням.
