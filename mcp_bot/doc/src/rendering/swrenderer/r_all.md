# r_all.cpp

## Призначення файлу
Файл містить точку входу або інтеграційні функції для software-рендера, забезпечує підключення рендерера до рушія гри.

## Короткий опис
Містить функції для ініціалізації, реєстрації, підключення software-рендера до основного рушія, інтеграції з іншими підсистемами.

## Основні сутності
- Функції для ініціалізації, реєстрації, підключення рендерера.

## Зв'язки з іншими модулями
Використовується рушієм гри для підключення software-рендера, взаємодіє з основним циклом гри, менеджером ресурсів, іншими рендерерами.
