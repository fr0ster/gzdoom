# r_skydrawer.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із малюванням неба у viewport software-рендера.

## Короткий опис
Оголошує інтерфейси, структури та функції для підготовки та рендерингу неба у вікні перегляду (viewport), обробки текстур, освітлення, ефектів.

## Основні сутності
- Структури для представлення параметрів неба.
- Оголошення функцій для рендерингу неба, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу неба, взаємодіє з менеджером текстур, буферами, освітленням.
