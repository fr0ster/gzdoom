# r_viewport.cpp

## Призначення файлу
Файл реалізує основні функції viewport у software-рендері: ініціалізація, рендеринг, управління ресурсами, очищення.

## Короткий опис
Містить реалізацію головного класу/структури viewport, функцій для підготовки сцени, рендерингу, управління буферами, текстурами, освітленням. Забезпечує інтеграцію viewport з іншими підсистемами рендеру.

## Основні сутності
- Головний клас/структура viewport.
- Функції для ініціалізації, рендерингу, очищення, управління ресурсами.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу у вікні перегляду, взаємодіє з геометрією, менеджером текстур, буферами, освітленням.
