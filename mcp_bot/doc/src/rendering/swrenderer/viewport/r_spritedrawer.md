# r_spritedrawer.cpp

## Призначення файлу
Файл реалізує функції для малювання спрайтів у viewport software-рендера: підготовка, рендеринг, обробка текстур, освітлення.

## Короткий опис
Містить реалізацію структур і функцій для рендерингу спрайтів у вікні перегляду, обробки текстур, освітлення, ефектів. Забезпечує коректне відображення спрайтів у сцені.

## Основні сутності
- Функції для рендерингу спрайтів, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу спрайтів, взаємодіє з менеджером текстур, буферами, освітленням.
