# r_viewport.h

## Призначення файлу
Головний заголовочний файл для viewport у software-рендері. Оголошує основні структури, класи та функції для організації рендерингу у вікні перегляду.

## Короткий опис
Оголошує інтерфейси, структури та функції для підготовки, рендерингу, управління буферами, текстурами, освітленням у viewport.

## Основні сутності
- Головний клас/структура viewport.
- Оголошення функцій для ініціалізації, рендерингу, очищення, управління ресурсами.

## Зв'язки з іншими модулями
Використовується software-рендерером для рендерингу у вікні перегляду, взаємодіє з геометрією, менеджером текстур, буферами, освітленням.
