# r_spandrawer.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із малюванням спанів (горизонтальних смуг) у viewport software-рендера.

## Короткий опис
Оголошує інтерфейси, структури та функції для підготовки та рендерингу спанів у вікні перегляду (viewport), обробки текстур, освітлення, ефектів.

## Основні сутності
- Структури для представлення параметрів спанів.
- Оголошення функцій для рендерингу спанів, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу спанів, взаємодіє з менеджером текстур, буферами, освітленням.
