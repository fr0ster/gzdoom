# r_spritedrawer.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із малюванням спрайтів у viewport software-рендера.

## Короткий опис
Оголошує інтерфейси, структури та функції для підготовки та рендерингу спрайтів у вікні перегляду (viewport), обробки текстур, освітлення, ефектів.

## Основні сутності
- Структури для представлення параметрів спрайтів.
- Оголошення функцій для рендерингу спрайтів, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу спрайтів, взаємодіє з менеджером текстур, буферами, освітленням.
