# r_walldrawer.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із малюванням стін у viewport software-рендера.

## Короткий опис
Оголошує інтерфейси, структури та функції для підготовки та рендерингу стін у вікні перегляду (viewport), обробки текстур, освітлення, ефектів.

## Основні сутності
- Структури для представлення параметрів стін.
- Оголошення функцій для рендерингу стін, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу стін, взаємодіє з менеджером текстур, буферами, освітленням.
