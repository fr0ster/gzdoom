# r_drawerargs.h

## Призначення файлу
Заголовочний файл для оголошення структур і функцій, пов'язаних із параметрами/аргументами малювання у viewport software-рендера.

## Короткий опис
Оголошує структури для передачі параметрів малювання (текстури, координати, кольори, освітлення) у функції рендерингу viewport.

## Основні сутності
- Структури для представлення аргументів малювання.
- Оголошення функцій для ініціалізації, використання параметрів малювання.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для передачі параметрів у функції рендерингу, взаємодіє з іншими модулями малювання, менеджером текстур, освітленням.
