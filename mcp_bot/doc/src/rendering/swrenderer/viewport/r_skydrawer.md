# r_skydrawer.cpp

## Призначення файлу
Файл реалізує функції для малювання неба у viewport software-рендера: підготовка, рендеринг, обробка текстур, освітлення.

## Короткий опис
Містить реалізацію структур і функцій для рендерингу неба у вікні перегляду, обробки текстур, освітлення, ефектів. Забезпечує коректне відображення неба у сцені.

## Основні сутності
- Функції для рендерингу неба, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу неба, взаємодіє з менеджером текстур, буферами, освітленням.
