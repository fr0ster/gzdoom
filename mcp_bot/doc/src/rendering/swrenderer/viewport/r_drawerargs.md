# r_drawerargs.cpp

## Призначення файлу
Файл реалізує функції для роботи з параметрами/аргументами малювання у viewport software-рендера: ініціалізація, передача, використання у функціях рендерингу.

## Короткий опис
Містить реалізацію структур і функцій для передачі параметрів малювання (текстури, координати, кольори, освітлення) у функції рендерингу viewport. Забезпечує коректну передачу даних між модулями малювання.

## Основні сутності
- Функції для ініціалізації, передачі, використання параметрів малювання.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для передачі параметрів у функції рендерингу, взаємодіє з іншими модулями малювання, менеджером текстур, освітленням.
