# r_walldrawer.cpp

## Призначення файлу
Файл реалізує функції для малювання стін у viewport software-рендера: підготовка, рендеринг, обробка текстур, освітлення.

## Короткий опис
Містить реалізацію структур і функцій для рендерингу стін у вікні перегляду, обробки текстур, освітлення, ефектів. Забезпечує коректне відображення стін у сцені.

## Основні сутності
- Функції для рендерингу стін, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу стін, взаємодіє з менеджером текстур, буферами, освітленням.
