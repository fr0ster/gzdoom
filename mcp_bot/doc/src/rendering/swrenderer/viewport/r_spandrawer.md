# r_spandrawer.cpp

## Призначення файлу
Файл реалізує функції для малювання спанів (горизонтальних смуг) у viewport software-рендера: підготовка, рендеринг, обробка текстур, освітлення.

## Короткий опис
Містить реалізацію структур і функцій для рендерингу спанів у вікні перегляду, обробки текстур, освітлення, ефектів. Забезпечує коректне відображення спанів у сцені.

## Основні сутності
- Функції для рендерингу спанів, обробки текстур, освітлення.

## Зв'язки з іншими модулями
Використовується viewport software-рендерером для рендерингу спанів, взаємодіє з менеджером текстур, буферами, освітленням.
