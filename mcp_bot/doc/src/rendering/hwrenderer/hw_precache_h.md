# hw_precache.h

## Призначення файлу
Заголовочний файл для оголошення функцій і структур, пов'язаних із попереднім завантаженням (precache) текстур, моделей, спрайтів у hardware-рендері.

## Короткий опис
Оголошує інтерфейси для збору, маркування та попереднього завантаження ресурсів, необхідних для рендерингу рівня. Забезпечує підготовку текстур, моделей, спрайтів до використання, щоб уникнути затримок під час гри.

## Основні сутності
- Оголошення функцій для precache текстур, моделей, спрайтів.
- Структури для маркування та збору ресурсів.

## Зв'язки з іншими модулями
Використовується hardware-рендером для оптимізації завантаження ресурсів, взаємодіє з менеджером текстур, моделей, відеосистемою.
