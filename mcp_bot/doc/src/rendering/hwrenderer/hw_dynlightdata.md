# hw_dynlightdata.cpp

## Призначення файлу
Файл реалізує обробку та зберігання даних динамічного освітлення для hardware-рендера.

## Короткий опис
Містить функції та структури для збору, оновлення та передачі інформації про динамічні джерела світла (лампи, спалахи, ефекти) у рендер. Забезпечує підготовку даних для шейдерів, оптимізацію розміщення світла, підтримку різних типів освітлення.

## Основні сутності
- Структури для зберігання параметрів динамічного світла.
- Функції для збору, оновлення, передачі даних у GPU.

## Зв'язки з іншими модулями
Використовується hardware-рендером для рендерингу динамічного освітлення, взаємодіє з менеджером шейдерів, геометрією сцени, ігровими об'єктами.
