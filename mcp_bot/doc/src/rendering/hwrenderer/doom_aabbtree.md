# doom_aabbtree.cpp

## Призначення файлу
Файл реалізує функції для роботи з AABB-деревом (Axis-Aligned Bounding Box tree) для геометрії рівня у hardware-рендері.

## Короткий опис
Містить реалізацію структур і функцій для побудови, оновлення, пошуку у AABB-дереві. Забезпечує оптимізацію рендерингу, колізій, трасування променів для геометрії рівня.

## Основні сутності
- Класи/структури для представлення вузлів AABB-дерева, операцій над деревом.
- Функції для побудови, оновлення, пошуку у дереві.

## Зв'язки з іншими модулями
Використовується hardware-рендером для оптимізації рендерингу, колізій, трасування променів, взаємодіє з геометрією рівня, системою фізики.
