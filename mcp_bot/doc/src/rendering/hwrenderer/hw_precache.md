# hw_precache.cpp

## Призначення файлу
Файл реалізує функції для попереднього завантаження (precache) текстур, спрайтів, моделей та інших ресурсів для hardware-рендера з метою оптимізації продуктивності та уникнення затримок під час гри.

## Короткий опис
Реалізує функції для збору та маркування всіх текстур, які можуть бути використані на поточному рівні, включаючи стіни, підлоги, небо, спрайти та моделі. Забезпечує попереднє створення необхідних ресурсів у відеопам'яті, видаляє невикористані моделі та текстури, щоб зменшити пікове споживання пам'яті. Використовує оголошення з hw_precache.h.

## Основні сутності
- PrecacheTexture, PrecacheSprite, PrecacheList — функції для попереднього завантаження окремих текстур і спрайтів.
- hw_PrecacheTexture — основна функція для збору та попереднього завантаження всіх необхідних ресурсів.
- Робота з маркуванням використаних текстур, моделей, спрайтів, очищення невикористаних ресурсів.

## Зв'язки з іншими модулями
Використовує менеджер текстур (TexMan), менеджер моделей (Models), класи для роботи з матеріалами (FMaterial), а також взаємодіє з відеосистемою (screen) та оголошеннями з hw_precache.h. Залежить від модулів рендерингу, ресурсів, акторів.
