# hw_entrypoint.cpp

## Призначення файлу
Файл містить точку входу та ініціалізацію hardware-рендера, а також основні функції запуску, налаштування та завершення роботи рендеру.

## Короткий опис
Реалізує ініціалізацію OpenGL/Vulkan/DirectX (залежно від реалізації), налаштування контексту рендерингу, підключення шейдерів, створення основних ресурсів. Може містити логіку для обробки помилок, перевірки сумісності, вибору режиму рендерингу.

## Основні сутності
- Функції ініціалізації та завершення роботи рендеру.
- Логіка для створення контексту, підключення драйверів, налаштування параметрів рендерингу.

## Зв'язки з іншими модулями
Викликається з основного рушія гри для запуску hardware-рендера, взаємодіє з модулями рендерингу, менеджером ресурсів, налаштуваннями відео.
