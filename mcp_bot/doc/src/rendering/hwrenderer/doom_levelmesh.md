# doom_levelmesh.cpp

## Призначення файлу
Файл реалізує функції для роботи з геометрією рівня у вигляді сітки (mesh) у hardware-рендері.

## Короткий опис
Містить реалізацію структур і функцій для створення, оновлення, оптимізації та рендерингу сітки рівня. Забезпечує інтеграцію геометрії рівня з рендером, підтримує роботу з вершинами, індексами, матеріалами, освітленням.

## Основні сутності
- Класи/структури для представлення сітки рівня, вершин, індексів.
- Функції для оновлення, оптимізації, рендерингу сітки.

## Зв'язки з іншими модулями
Використовується hardware-рендером для рендерингу геометрії рівня, взаємодіє з менеджером матеріалів, буферами вершин, системою освітлення.
