# hw_models.cpp

## Призначення файлу
Файл реалізує функції для роботи з 3D-моделями у hardware-рендері: завантаження, ініціалізація, рендеринг, управління матеріалами та скінами.

## Короткий опис
Містить реалізацію класів і функцій для обробки 3D-моделей різних форматів, їхніх матеріалів, скіна, анімацій. Забезпечує інтеграцію моделей у рендеринг, підтримує різні типи анімацій, трансформацій, освітлення.

## Основні сутності
- Класи для представлення моделей, скіна, анімацій.
- Функції для завантаження, ініціалізації, рендерингу моделей.
- Логіка для роботи з матеріалами, текстурами, освітленням моделей.

## Зв'язки з іншими модулями
Використовується hardware-рендером для відображення 3D-моделей, взаємодіє з менеджером текстур, матеріалів, а також з ігровими об'єктами (акторами), які можуть мати 3D-моделі.
