# doom_levelmesh.h

## Призначення файлу
Заголовочний файл для визначення структур і класів, пов'язаних із сіткою рівня (level mesh) у hardware-рендері.

## Короткий опис
Оголошує структури для представлення геометрії рівня у вигляді сітки (mesh), що використовується для рендерингу. Визначає інтерфейси для роботи з вершинами, індексами, матеріалами, а також для оновлення та оптимізації геометрії.

## Основні сутності
- Класи/структури для представлення сітки рівня, вершин, індексів.
- Оголошення функцій для оновлення, оптимізації, рендерингу сітки.

## Зв'язки з іншими модулями
Використовується hardware-рендером для рендерингу геометрії рівня, взаємодіє з менеджером матеріалів, буферами вершин, системою освітлення.
