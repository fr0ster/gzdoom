# doom_aabbtree.h

## Призначення файлу
Заголовочний файл для визначення структур і класів, пов'язаних із AABB-деревом (Axis-Aligned Bounding Box tree) для геометрії рівня у hardware-рендері.

## Короткий опис
Оголошує структури для просторової ієрархії (AABB-дерево), що використовується для оптимізації рендерингу, колізій, трасування променів. Визначає інтерфейси для побудови, оновлення та використання дерева.

## Основні сутності
- Класи/структури для представлення вузлів AABB-дерева, операцій над деревом.
- Оголошення функцій для побудови, оновлення, пошуку у дереві.

## Зв'язки з іншими модулями
Використовується hardware-рендером для оптимізації рендерингу, колізій, трасування променів, взаємодіє з геометрією рівня, системою фізики.
