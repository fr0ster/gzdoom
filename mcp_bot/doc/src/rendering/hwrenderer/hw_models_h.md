# hw_models.h

## Призначення файлу
Заголовочний файл для визначення структур і класів, пов'язаних із 3D-моделями у hardware-рендері. Містить інтерфейси для роботи з моделями, їхніми властивостями та взаємодією з рендером.

## Короткий опис
Оголошує класи, структури та функції для завантаження, зберігання та рендерингу 3D-моделей у грі. Визначає інтерфейси для роботи з різними форматами моделей, їхніми матеріалами, скінами, анімаціями тощо.

## Основні сутності
- Класи/структури для представлення 3D-моделей, скіна, анімацій.
- Оголошення функцій для завантаження, ініціалізації та рендерингу моделей.

## Зв'язки з іншими модулями
Використовується hardware-рендером для відображення 3D-моделей, взаємодіє з менеджером текстур, матеріалів, а також з ігровими об'єктами (акторами), які можуть мати 3D-моделі.
