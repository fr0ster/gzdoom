# sc_man_scanner.re

## Призначення файлу
Файл `sc_man_scanner.re` містить реалізацію лексичного аналізатора (сканера) для скриптової мови гри, написану з використанням інструменту re2c.

## Короткий опис
Цей файл реалізує лексичний аналізатор, який розбиває вхідний текст скрипту на токени (лексеми) для подальшого синтаксичного аналізу. Він підтримує різні режими сканування для різних контекстів, включаючи класичний режим Hexen, режим DECORATE та режим для станів акторів.

## Структура файлу
Файл містить:
1. Визначення макросів для re2c
2. Реалізацію різних режимів сканування
3. Обробку спеціальних випадків (коментарі, рядки, нові рядки)
4. Обробку токенів та їх перетворення у внутрішнє представлення

## Основні сутності

### Макроси для re2c
```cpp
#define YYCTYPE     unsigned char
#define YYCURSOR    cursor
#define YYLIMIT     limit
#define YYMARKER    marker
#define YYFILL(n)   {}
```

#### Призначення
Ці макроси визначають типи та змінні, які використовуються інструментом re2c для генерації коду лексичного аналізатора. Вони вказують, як re2c повинен звертатися до вхідного буфера та керувати скануванням.

### Режими сканування
Файл містить три основні режими сканування:
1. Режим для станів акторів (`StateMode != 0`)
2. Режим для токенів (`tokens`)
3. Класичний режим Hexen (`!CMode`)
4. Модифікований режим Hexen для DECORATE (`CMode`)

#### Призначення
Різні режими сканування дозволяють аналізатору правильно обробляти різні контексти в скриптовій мові. Наприклад, режим для станів акторів має спеціальні правила для обробки станів, а режим DECORATE має додаткові правила для обробки специфічних конструкцій DECORATE.

### Обробка коментарів
```cpp
comment:
/*!re2c
    "*/"
        {
            if (YYCURSOR >= YYLIMIT)
            {
                ScriptPtr = ScriptEndPtr;
                return_val = false;
                goto end;
            }
            goto std1;
        }
    "\n"
        {
            if (YYCURSOR >= YYLIMIT)
            {
                ScriptPtr = ScriptEndPtr;
                return_val = false;
                goto end;
            }
            Line++;
            Crossed = true;
            goto comment;
        }
    any             { goto comment; }
*/
```

#### Призначення
Цей блок коду обробляє C-стиль коментарі (`/* ... */`). Він пропускає всі символи до закриваючої послідовності `*/`, збільшуючи лічильник рядків при зустрічі символу нового рядка.

### Обробка нових рядків
```cpp
newline:
    if (YYCURSOR >= YYLIMIT)
    {
        ScriptPtr = ScriptEndPtr;
        return_val = false;
        goto end;
    }
    Line++;
    Crossed = true;
    goto std1;
```

#### Призначення
Цей блок коду обробляє символи нового рядка, збільшуючи лічильник рядків та встановлюючи прапорець `Crossed`, який вказує, що був перетнутий новий рядок.

### Обробка токенів
```cpp
normal_token:
    ScriptPtr = (YYCURSOR >= YYLIMIT) ? ScriptEndPtr : cursor;
    StringLen = int(ScriptPtr - tok);
    // ...
```

#### Призначення
Цей блок коду обробляє звичайні токени, зберігаючи їх у буфері та встановлюючи відповідні змінні для подальшого аналізу.

### Обробка рядкових констант
```cpp
string_const:
    for (const char *c = tok; c < YYCURSOR; ++c)
    {
        if (*c == '\n') ++Line;
    }
    RET(TK_StringConst);
```

#### Призначення
Цей блок коду обробляє рядкові константи, підраховуючи кількість нових рядків у рядку та повертаючи токен `TK_StringConst`.

### Обробка рядків
```cpp
string:
    if (YYLIMIT != ScriptEndPtr)
    {
        ScriptPtr = ScriptEndPtr;
        return_val = false;
        goto end;
    }
    // ...
```

#### Призначення
Цей блок коду обробляє рядки, враховуючи escape-послідовності та перенесення рядків. Він також обробляє випадок, коли рядок перевищує максимальний розмір буфера.

### Обробка від'ємних чисел
```cpp
negative_check:
    // re2c doesn't have enough state to handle '-' as the start of a negative number
    // and as its own token, so help it out a little.
    TokenType = '-';
    if (YYCURSOR >= YYLIMIT)
    {
        goto normal_token;
    }
    // ...
```

#### Призначення
Цей блок коду обробляє спеціальний випадок, коли символ `-` може бути як оператором віднімання, так і початком від'ємного числа. Оскільки re2c не має достатньо стану для обробки цього випадку, код допомагає йому, перевіряючи наступний символ.

### Визначення токенів
Файл містить велику кількість визначень токенів для різних ключових слів, операторів та літералів. Наприклад:

```cpp
'break'                     { RET(TK_Break); }
'case'                      { RET(TK_Case); }
'const'                     { RET(TK_Const); }
// ...
```

#### Призначення
Ці визначення вказують, які токени повинні бути повернуті для різних ключових слів та операторів. Вони також враховують версію парсера для підтримки зворотної сумісності.

## Зв'язки з іншими модулями
Файл `sc_man_scanner.re` тісно пов'язаний з системою скриптування гри. Він використовується для розбору скриптів, які визначають поведінку гри, включаючи стани акторів, дії та інші аспекти геймплею.

Цей файл є частиною системи лексичного аналізу, яка працює разом з `sc_man.cpp` та `sc_man.h` для забезпечення повного аналізу скриптів. Він також використовує токени, визначені в `sc_man_tokens.h`.

Файл використовує інструмент re2c для генерації ефективного коду лексичного аналізатора. re2c перетворює регулярні вирази в оптимізований C-код, який виконує лексичний аналіз.
