# serialize_obj.h

## Призначення файлу
Файл `serialize_obj.h` містить шаблонні функції для серіалізації об'єктів типу `TObjPtr`, які є вказівниками на об'єкти в грі.

## Короткий опис
Цей файл визначає спеціалізовані шаблонні функції для серіалізації вказівників на об'єкти типу `TObjPtr`. Він виділений в окремий заголовочний файл, оскільки вимагає включення деяких "брудних" заголовків, які не повинні бути частиною основного файлу `serializer.h`.

## Структура файлу
```cpp
#pragma once

// These are in a separate header because they require some rather 'dirty' headers to work which should not be part of serializer.h

template<class T>
FSerializer &Serialize(FSerializer &arc, const char *key, TObjPtr<T> &value, TObjPtr<T> *)
{
    Serialize(arc, key, value.o, nullptr);
    return arc; 
}

template<class T>
FSerializer &Serialize(FSerializer &arc, const char *key, TObjPtr<T> &value, T *)
{
    Serialize(arc, key, value.o, nullptr);
    return arc;
}
```

## Основні сутності

### Шаблонна функція Serialize для TObjPtr<T> з другим параметром TObjPtr<T>*
```cpp
template<class T>
FSerializer &Serialize(FSerializer &arc, const char *key, TObjPtr<T> &value, TObjPtr<T> *)
```

#### Призначення
Ця функція серіалізує об'єкт типу `TObjPtr<T>`, делегуючи серіалізацію внутрішньому вказівнику `o`.

#### Параметри
- **arc**: Посилання на об'єкт `FSerializer`, який виконує серіалізацію.
- **key**: Ключ, під яким об'єкт буде серіалізований.
- **value**: Посилання на об'єкт `TObjPtr<T>`, який потрібно серіалізувати.
- **dummy**: Вказівник на `TObjPtr<T>`, який використовується для вибору правильної перевантаженої функції (не використовується в тілі функції).

#### Повертає
Посилання на об'єкт `FSerializer` для підтримки ланцюжка викликів.

#### Особливості реалізації
Функція делегує серіалізацію внутрішньому вказівнику `o` об'єкта `TObjPtr<T>`, викликаючи функцію `Serialize` для цього вказівника.

### Шаблонна функція Serialize для TObjPtr<T> з другим параметром T*
```cpp
template<class T>
FSerializer &Serialize(FSerializer &arc, const char *key, TObjPtr<T> &value, T *)
```

## Зв'язки з іншими модулями
Файл `serialize_obj.h` тісно пов'язаний з системою серіалізації гри, зокрема з файлом `serializer.h`, який визначає основні функції та класи для серіалізації об'єктів. Він також пов'язаний з класом `TObjPtr`, який є шаблонним класом для вказівників на об'єкти в грі.

Цей файл використовується для серіалізації об'єктів типу `TObjPtr`, які є вказівниками на об'єкти в грі, що дозволяє зберігати та відновлювати стан гри, включаючи всі об'єкти та їх зв'язки.
