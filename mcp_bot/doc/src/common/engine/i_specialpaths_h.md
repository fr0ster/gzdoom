# i_specialpaths.h

## Призначення файлу
Файл `i_specialpaths.h` визначає функції для отримання шляхів до спеціальних директорій, які використовуються грою для зберігання даних, конфігурацій, знімків екрану та інших файлів.

## Короткий опис
Цей файл містить набір функцій для отримання платформо-незалежних шляхів до різних директорій, які використовуються грою. Функції забезпечують доступ до директорій для зберігання даних програми, кешу, конфігураційних файлів, знімків екрану, збережених ігор, демо-записів тощо. Файл також містить платформо-специфічні функції для Unix-подібних систем та macOS.

## Структура файлу
```cpp
#pragma once

#include "zstring.h"

#if defined(__unix__) || defined(__HAIKU__)
FString GetUserFile (const char *path);
#endif
FString M_GetAppDataPath(bool create);
FString M_GetCachePath(bool create);
FString M_GetAutoexecPath();
FString M_GetConfigPath(bool for_reading);
FString M_GetScreenshotsPath();
FString M_GetSavegamesPath();
FString M_GetDocumentsPath();
FString M_GetDemoPath();

FString M_GetNormalizedPath(const char* path);

#ifdef __APPLE__
FString M_GetMacAppSupportPath(const bool create = true);
void M_GetMacSearchDirectories(FString& user_docs, FString& user_app_support, FString& local_app_support);
#endif // __APPLE__
```

## Основні сутності

### GetUserFile
Функція для отримання шляху до файлу користувача (доступна тільки на Unix-подібних системах та Haiku).

#### Призначення
Повертає шлях до файлу в домашній директорії користувача.

#### Параметри
- **path**: Відносний шлях до файлу.

#### Повертає
Об'єкт `FString`, що містить повний шлях до файлу користувача.

#### Особливості реалізації
Функція доступна тільки на Unix-подібних системах та Haiku, де використовується концепція домашньої директорії користувача.

### M_GetAppDataPath
Функція для отримання шляху до директорії даних програми.

#### Призначення
Повертає шлях до директорії, де програма може зберігати свої дані.

#### Параметри
- **create**: Прапорець, що вказує, чи потрібно створити директорію, якщо вона не існує.

#### Повертає
Об'єкт `FString`, що містить шлях до директорії даних програми.

#### Зв'язки з іншими модулями
Використовується різними підсистемами гри для зберігання даних, таких як конфігураційні файли, збережені ігри тощо.

### M_GetCachePath
Функція для отримання шляху до директорії кешу.

#### Призначення
Повертає шлях до директорії, де програма може зберігати тимчасові дані.

#### Параметри
- **create**: Прапорець, що вказує, чи потрібно створити директорію, якщо вона не існує.

#### Повертає
Об'єкт `FString`, що містить шлях до директорії кешу.

#### Зв'язки з іншими модулями
Використовується для зберігання тимчасових даних, таких як кеш текстур, звуків тощо.

### M_GetAutoexecPath
Функція для отримання шляху до файлу автозапуску.

#### Призначення
Повертає шлях до файлу автозапуску, який виконується при запуску гри.

#### Повертає
Об'єкт `FString`, що містить шлях до файлу автозапуску.

#### Зв'язки з іншими модулями
Використовується системою консольних команд для завантаження та виконання команд при запуску гри.

### M_GetConfigPath
Функція для отримання шляху до конфігураційного файлу.

#### Призначення
Повертає шлях до конфігураційного файлу гри.

#### Параметри
- **for_reading**: Прапорець, що вказує, чи файл буде використовуватися для читання.

#### Повертає
Об'єкт `FString`, що містить шлях до конфігураційного файлу.

#### Зв'язки з іншими модулями
Використовується системою конфігурації для завантаження та збереження налаштувань гри.

### M_GetScreenshotsPath
Функція для отримання шляху до директорії знімків екрану.

#### Призначення
Повертає шлях до директорії, де зберігаються знімки екрану.

#### Повертає
Об'єкт `FString`, що містить шлях до директорії знімків екрану.

#### Зв'язки з іншими модулями
Використовується системою знімків екрану для збереження зображень.

### M_GetSavegamesPath
Функція для отримання шляху до директорії збережених ігор.

#### Призначення
Повертає шлях до директорії, де зберігаються збережені ігри.

#### Повертає
Об'єкт `FString`, що містить шлях до директорії збережених ігор.

#### Зв'язки з іншими модулями
Використовується системою збереження ігор для завантаження та збереження стану гри.

### M_GetDocumentsPath
Функція для отримання шляху до директорії документів.

#### Призначення
Повертає шлях до директорії документів користувача.

#### Повертає
Об'єкт `FString`, що містить шлях до директорії документів.

#### Зв'язки з іншими модулями
Використовується для доступу до файлів, які можуть бути розміщені в директорії документів користувача.

### M_GetDemoPath
Функція для отримання шляху до директорії демо-записів.

#### Призначення
Повертає шлях до директорії, де зберігаються демо-записи.

#### Повертає
Об'єкт `FString`, що містить шлях до директорії демо-записів.

#### Зв'язки з іншими модулями
Використовується системою демо-записів для завантаження та збереження записів ігрового процесу.

### M_GetNormalizedPath
Функція для нормалізації шляху.

#### Призначення
Перетворює шлях у нормалізовану форму, замінюючи символи роздільника шляху на стандартні для поточної платформи.

#### Параметри
- **path**: Шлях, який потрібно нормалізувати.

#### Повертає
Об'єкт `FString`, що містить нормалізований шлях.

#### Зв'язки з іншими модулями
Використовується різними підсистемами для забезпечення коректної роботи з шляхами на різних платформах.

### M_GetMacAppSupportPath
Функція для отримання шляху до директорії підтримки програми на macOS (доступна тільки на macOS).

#### Призначення
Повертає шлях до директорії підтримки програми на macOS.

#### Параметри
- **create**: Прапорець, що вказує, чи потрібно створити директорію, якщо вона не існує (за замовчуванням true).

#### Повертає
Об'єкт `FString`, що містить шлях до директорії підтримки програми на macOS.

#### Особливості реалізації
Функція доступна тільки на macOS, де використовується концепція директорії підтримки програми.

### M_GetMacSearchDirectories
Функція для отримання шляхів до директорій пошуку на macOS (доступна тільки на macOS).

#### Призначення
Заповнює передані параметри шляхами до різних директорій пошуку на macOS.

#### Параметри
- **user_docs**: Посилання на об'єкт `FString`, який буде заповнено шляхом до директорії документів користувача.
- **user_app_support**: Посилання на об'єкт `FString`, який буде заповнено шляхом до директорії підтримки програми користувача.
- **local_app_support**: Посилання на об'єкт `FString`, який буде заповнено шляхом до локальної директорії підтримки програми.

#### Особливості реалізації
Функція доступна тільки на macOS, де використовується концепція різних директорій пошуку.

## Зв'язки з іншими модулями
Функції, визначені в цьому файлі, використовуються різними підсистемами гри для доступу до файлів та директорій. Вони забезпечують платформо-незалежний спосіб отримання шляхів до спеціальних директорій, які використовуються грою для зберігання даних, конфігурацій, знімків екрану та інших файлів.
