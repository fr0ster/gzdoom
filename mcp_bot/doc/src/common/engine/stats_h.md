# stats.h

## Призначення файлу
Файл `stats.h` визначає класи та функції для вимірювання продуктивності та збору статистики в грі.

## Короткий опис
Цей файл містить класи для вимірювання часу виконання коду (`cycle_t` та `glcycle_t`), а також систему для реєстрації та відображення статистичних даних (`FStat`). Реалізація класу `cycle_t` відрізняється залежно від платформи, використовуючи найбільш ефективні методи вимірювання часу для кожної платформи.

## Структура файлу
Файл містить:
1. Реалізацію класу `cycle_t` для різних платформ (Windows, macOS, Linux)
2. Клас `glcycle_t`, який є розширенням `cycle_t` для вимірювання часу в OpenGL
3. Допоміжний клас `Clocker` для автоматичного вимірювання часу виконання блоку коду
4. Клас `FStat` для реєстрації та відображення статистичних даних
5. Макрос `ADD_STAT` для спрощення додавання нових статистичних даних

## Основні сутності

### Клас cycle_t
```cpp
class cycle_t
{
public:
    void Reset();
    void Clock();
    void ResetAndClock();
    void Unclock(bool checkvar = true);
    double Time();
    double TimeMS();
    int64_t GetRawCounter();

private:
    int64_t Counter;
};
```

#### Призначення
Клас `cycle_t` використовується для вимірювання часу виконання коду. Він використовує різні методи вимірювання часу залежно від платформи, такі як `rdtsc` на x86/x64 або `clock_gettime` на Linux.

#### Методи
- **Reset()**: Скидає лічильник часу.
- **Clock()**: Починає вимірювання часу.
- **ResetAndClock()**: Скидає лічильник і починає вимірювання часу.
- **Unclock(bool checkvar = true)**: Закінчує вимірювання часу.
- **Time()**: Повертає виміряний час у секундах.
- **TimeMS()**: Повертає виміряний час у мілісекундах.
- **GetRawCounter()**: Повертає сирий лічильник часу.

### Функція rdtsc
```cpp
inline uint64_t rdtsc();
```

#### Призначення
Функція `rdtsc` використовується для отримання значення лічильника часу процесора (Time Stamp Counter) на різних архітектурах. Вона має різні реалізації для різних архітектур (x86, x64, PowerPC, ARM64).

### Клас glcycle_t
```cpp
class glcycle_t : public cycle_t
{
public:
    static bool active;
    void Clock();
    void Unclock();
};
```

#### Призначення
Клас `glcycle_t` є розширенням класу `cycle_t` для вимірювання часу в OpenGL. Він має статичний прапорець `active`, який дозволяє вмикати або вимикати вимірювання часу.

#### Поля
- **active**: Статичний прапорець, який вказує, чи активне вимірювання часу.

#### Методи
- **Clock()**: Починає вимірювання часу, якщо `active` дорівнює `true`.
- **Unclock()**: Закінчує вимірювання часу, якщо `active` дорівнює `true`.

### Клас Clocker
```cpp
class Clocker
{
public:
    explicit Clocker(glcycle_t& clck);
    ~Clocker();
    Clocker(const Clocker&) = delete;
    Clocker& operator=(const Clocker&) = delete;
private:
    glcycle_t & clock;
};
```

#### Призначення
Клас `Clocker` є допоміжним класом для автоматичного вимірювання часу виконання блоку коду. Він використовує RAII (Resource Acquisition Is Initialization) для автоматичного виклику `Clock()` при створенні об'єкта та `Unclock()` при його знищенні.

#### Методи
- **Clocker(glcycle_t& clck)**: Конструктор, який починає вимірювання часу.
- **~Clocker()**: Деструктор, який закінчує вимірювання часу.

### Клас FStat
```cpp
class FStat
{
public:
    FStat(const char *name);
    virtual ~FStat();

    virtual FString GetStats() = 0;

    void ToggleStat();
    bool isActive() const;

    static void PrintStat(F2DDrawer *drawer);
    static FStat *FindStat(const char *name);
    static void ToggleStat(const char *name);
    static void EnableStat(const char* name, bool on);
    static void DumpRegisteredStats();

private:
    FStat *m_Next;
    const char *m_Name;
    bool m_Active;

    static FStat *FirstStat;
};
```

#### Призначення
Клас `FStat` є базовим класом для реєстрації та відображення статистичних даних. Він дозволяє створювати різні типи статистичних даних, які можуть бути увімкнені або вимкнені під час виконання.

#### Поля
- **m_Next**: Вказівник на наступний об'єкт `FStat` у зв'язаному списку.
- **m_Name**: Назва статистичних даних.
- **m_Active**: Прапорець, який вказує, чи активні статистичні дані.
- **FirstStat**: Статичний вказівник на перший об'єкт `FStat` у зв'язаному списку.

#### Методи
- **FStat(const char *name)**: Конструктор, який реєструє статистичні дані з вказаною назвою.
- **~FStat()**: Деструктор, який видаляє статистичні дані зі зв'язаного списку.
- **GetStats()**: Віртуальний метод, який повертає рядок зі статистичними даними.
- **ToggleStat()**: Вмикає або вимикає статистичні дані.
- **isActive()**: Перевіряє, чи активні статистичні дані.
- **PrintStat(F2DDrawer *drawer)**: Статичний метод, який відображає всі активні статистичні дані.
- **FindStat(const char *name)**: Статичний метод, який знаходить статистичні дані за назвою.
- **ToggleStat(const char *name)**: Статичний метод, який вмикає або вимикає статистичні дані за назвою.
- **EnableStat(const char* name, bool on)**: Статичний метод, який вмикає або вимикає статистичні дані за назвою.
- **DumpRegisteredStats()**: Статичний метод, який виводить список всіх зареєстрованих статистичних даних.

### Макрос ADD_STAT
```cpp
#define ADD_STAT(n) \
    static class Stat_##n : public FStat { \
        public: \
            Stat_##n () : FStat (#n) {} \
        FString GetStats (); } Istaticstat##n; \
    FString Stat_##n::GetStats ()
```

#### Призначення
Макрос `ADD_STAT` спрощує додавання нових статистичних даних. Він створює новий клас, який успадковується від `FStat`, і реалізує метод `GetStats()`.

## Зв'язки з іншими модулями
Файл `stats.h` пов'язаний з системою вимірювання продуктивності та відображення статистичних даних. Він використовується різними частинами гри для вимірювання часу виконання коду та збору статистичних даних.

Клас `cycle_t` використовується для вимірювання часу виконання коду, а клас `FStat` - для реєстрації та відображення статистичних даних. Макрос `ADD_STAT` спрощує додавання нових статистичних даних.

Файл також пов'язаний з системою відображення, оскільки метод `PrintStat` використовує клас `F2DDrawer` для відображення статистичних даних на екрані.
