# printf.h

## Призначення файлу
Файл `printf.h` визначає функції та константи для форматованого виведення тексту в грі, включаючи кольорове форматування, рівні виведення та обробку помилок.

## Короткий опис
Цей файл містить визначення функцій для форматованого виведення тексту, подібних до стандартної функції `printf`, але з додатковими можливостями, такими як кольорове форматування та різні рівні виведення. Також файл містить визначення констант для кольорів тексту, рівнів виведення та прапорців для функцій виведення. Файл використовує бібліотеку `stb_sprintf` для форматування рядків.

## Структура файлу
```cpp
#pragma once
#include <stdarg.h>

#if defined __GNUC__ || defined __clang__
# define ATTRIBUTE(attrlist) __attribute__(attrlist)
#else
# define ATTRIBUTE(attrlist)
#endif

#include "stb_sprintf.h"

// This header collects all things printf, so that this doesn't need to pull in other, far more dirty headers, just for outputting some text.
extern "C" int mysnprintf(char* buffer, size_t count, const char* format, ...) ATTRIBUTE((format(printf, 3, 4)));
extern "C" int myvsnprintf(char* buffer, size_t count, const char* format, va_list argptr) ATTRIBUTE((format(printf, 3, 0)));

#define TEXTCOLOR_ESCAPE        '\034'
#define TEXTCOLOR_ESCAPESTR     "\034"

// ... (визначення кольорів тексту)

// game print flags
enum
{
    PRINT_LOW,      // pickup messages
    PRINT_MEDIUM,   // death messages
    PRINT_HIGH,     // critical messages
    PRINT_CHAT,     // chat messages
    PRINT_TEAMCHAT, // chat messages from a teammate
    PRINT_LOG,      // only to logfile
    PRINT_BOLD = 200,               // What Printf_Bold used
    PRINT_TYPES = 1023,     // Bitmask.
    PRINT_NONOTIFY = 1024,  // Flag - do not add to notify buffer
    PRINT_NOLOG = 2048,     // Flag - do not print to log file
    PRINT_NOTIFY = 4096,    // Flag - add to game-native notify display - messages without this only go to the generic notification buffer.
};

enum
{
    DMSG_OFF,       // no developer messages.
    DMSG_ERROR,     // general notification messages
    DMSG_WARNING,   // warnings
    DMSG_NOTIFY,    // general notification messages
    DMSG_SPAMMY,    // for those who want to see everything, regardless of its usefulness.
};

[[noreturn]] void I_Error(const char *fmt, ...) ATTRIBUTE((format(printf,1,2)));
[[noreturn]] void I_FatalError(const char* fmt, ...) ATTRIBUTE((format(printf, 1, 2)));

// This really could need some cleanup - the main problem is that it'd create
// lots of potential for merge conflicts.

int PrintString (int iprintlevel, const char *outline);
int VPrintf(int printlevel, const char* format, va_list parms);
int Printf (int printlevel, const char *format, ...) ATTRIBUTE((format(printf,2,3)));
int Printf (const char *format, ...) ATTRIBUTE((format(printf,1,2)));
int DPrintf (int level, const char *format, ...) ATTRIBUTE((format(printf,2,3)));

void I_DebugPrint(const char* cp);
void I_DebugPrintf(const char* fmt, ...);   // Prints to the debugger's log.

// flag to silence non-error output
extern bool batchrun;
```

## Основні сутності

### Макроси для атрибутів компілятора
- **ATTRIBUTE**: Макрос для визначення атрибутів функцій для компіляторів GCC та Clang. Використовується для перевірки форматних рядків під час компіляції.

### Функції форматування рядків
- **mysnprintf**: Функція для форматування рядка та запису його в буфер.
- **myvsnprintf**: Функція для форматування рядка з використанням списку аргументів `va_list` та запису його в буфер.

### Константи для кольорового форматування тексту
- **TEXTCOLOR_ESCAPE**: Символ, який використовується для позначення початку кольорового форматування.
- **TEXTCOLOR_ESCAPESTR**: Рядкове представлення символу `TEXTCOLOR_ESCAPE`.
- **TEXTCOLOR_BRICK**, **TEXTCOLOR_TAN**, **TEXTCOLOR_GRAY**, **TEXTCOLOR_GREEN**, **TEXTCOLOR_BROWN**, **TEXTCOLOR_GOLD**, **TEXTCOLOR_RED**, **TEXTCOLOR_BLUE**, **TEXTCOLOR_ORANGE**, **TEXTCOLOR_WHITE**, **TEXTCOLOR_YELLOW**, **TEXTCOLOR_UNTRANSLATED**, **TEXTCOLOR_BLACK**, **TEXTCOLOR_LIGHTBLUE**, **TEXTCOLOR_CREAM**, **TEXTCOLOR_OLIVE**, **TEXTCOLOR_DARKGREEN**, **TEXTCOLOR_DARKRED**, **TEXTCOLOR_DARKBROWN**, **TEXTCOLOR_PURPLE**, **TEXTCOLOR_DARKGRAY**, **TEXTCOLOR_CYAN**, **TEXTCOLOR_ICE**, **TEXTCOLOR_FIRE**, **TEXTCOLOR_SAPPHIRE**, **TEXTCOLOR_TEAL**: Константи для різних кольорів тексту.
- **TEXTCOLOR_NORMAL**, **TEXTCOLOR_BOLD**: Константи для нормального та жирного тексту.
- **TEXTCOLOR_CHAT**, **TEXTCOLOR_TEAMCHAT**: Константи для тексту чату та командного чату.

### Рівні виведення
Перелічення, що визначає різні рівні виведення повідомлень:
- **PRINT_LOW**: Повідомлення про підбирання предметів.
- **PRINT_MEDIUM**: Повідомлення про смерть.
- **PRINT_HIGH**: Критичні повідомлення.
- **PRINT_CHAT**: Повідомлення чату.
- **PRINT_TEAMCHAT**: Повідомлення командного чату.
- **PRINT_LOG**: Тільки для запису в лог-файл.
- **PRINT_BOLD**: Жирний текст.
- **PRINT_TYPES**: Бітова маска для типів повідомлень.
- **PRINT_NONOTIFY**: Прапорець - не додавати до буфера повідомлень.
- **PRINT_NOLOG**: Прапорець - не записувати в лог-файл.
- **PRINT_NOTIFY**: Прапорець - додавати до нативного буфера повідомлень гри.

### Рівні повідомлень розробника
Перелічення, що визначає різні рівні повідомлень розробника:
- **DMSG_OFF**: Без повідомлень розробника.
- **DMSG_ERROR**: Повідомлення про помилки.
- **DMSG_WARNING**: Попередження.
- **DMSG_NOTIFY**: Загальні повідомлення.
- **DMSG_SPAMMY**: Для тих, хто хоче бачити все, незалежно від його корисності.

### Функції для виведення помилок
- **I_Error**: Функція для виведення повідомлення про помилку та завершення програми.
- **I_FatalError**: Функція для виведення повідомлення про фатальну помилку та завершення програми.

### Функції для виведення тексту
- **PrintString**: Функція для виведення рядка з вказаним рівнем виведення.
- **VPrintf**: Функція для форматованого виведення з використанням списку аргументів `va_list`.
- **Printf**: Перевантажені функції для форматованого виведення з вказаним рівнем виведення або з рівнем за замовчуванням.
- **DPrintf**: Функція для форматованого виведення повідомлень розробника з вказаним рівнем.
- **I_DebugPrint**: Функція для виведення рядка в лог відлагоджувача.
- **I_DebugPrintf**: Функція для форматованого виведення в лог відлагоджувача.

### Глобальні змінні
- **batchrun**: Прапорець для вимкнення виведення, що не є помилками.

## Детальний опис основних сутностей

### mysnprintf
Функція для форматування рядка та запису його в буфер.

#### Призначення
Форматує рядок за допомогою бібліотеки `stb_sprintf` та записує його в буфер.

#### Параметри
- **buffer**: Буфер для запису результату.
- **count**: Розмір буфера.
- **format**: Форматний рядок.
- **...**: Аргументи для форматування.

#### Повертає
Кількість символів, які були б записані в буфер, якщо б він був достатньо великим, не враховуючи нульовий символ.

#### Особливості реалізації
Використовує бібліотеку `stb_sprintf` для форматування рядків.

### myvsnprintf
Функція для форматування рядка з використанням списку аргументів `va_list` та запису його в буфер.

#### Призначення
Форматує рядок за допомогою бібліотеки `stb_sprintf` та списку аргументів `va_list` та записує його в буфер.

#### Параметри
- **buffer**: Буфер для запису результату.
- **count**: Розмір буфера.
- **format**: Форматний рядок.
- **argptr**: Список аргументів.

#### Повертає
Кількість символів, які були б записані в буфер, якщо б він був достатньо великим, не враховуючи нульовий символ.

#### Особливості реалізації
Використовує бібліотеку `stb_sprintf` для форматування рядків.

### I_Error
Функція для виведення повідомлення про помилку та завершення програми.

#### Призначення
Виводить повідомлення про помилку та завершує програму.

#### Параметри
- **fmt**: Форматний рядок.
- **...**: Аргументи для форматування.

#### Особливості реалізації
Функція не повертається (має атрибут `[[noreturn]]`).

### I_FatalError
Функція для виведення повідомлення про фатальну помилку та завершення програми.

#### Призначення
Виводить повідомлення про фатальну помилку та завершує програму.

#### Параметри
- **fmt**: Форматний рядок.
- **...**: Аргументи для форматування.

#### Особливості реалізації
Функція не повертається (має атрибут `[[noreturn]]`).

### PrintString
Функція для виведення рядка з вказаним рівнем виведення.

#### Призначення
Виводить рядок з вказаним рівнем виведення.

#### Параметри
- **iprintlevel**: Рівень виведення.
- **outline**: Рядок для виведення.

#### Повертає
Кількість виведених символів.

### VPrintf
Функція для форматованого виведення з використанням списку аргументів `va_list`.

#### Призначення
Форматує рядок за допомогою списку аргументів `va_list` та виводить його з вказаним рівнем виведення.

#### Параметри
- **printlevel**: Рівень виведення.
- **format**: Форматний рядок.
- **parms**: Список аргументів.

#### Повертає
Кількість виведених символів.

### Printf
Перевантажені функції для форматованого виведення.

#### Призначення
Форматує рядок та виводить його з вказаним рівнем виведення або з рівнем за замовчуванням.

#### Параметри (перша перевантажена версія)
- **printlevel**: Рівень виведення.
- **format**: Форматний рядок.
- **...**: Аргументи для форматування.

#### Параметри (друга перевантажена версія)
- **format**: Форматний рядок.
- **...**: Аргументи для форматування.

#### Повертає
Кількість виведених символів.

### DPrintf
Функція для форматованого виведення повідомлень розробника.

#### Призначення
Форматує рядок та виводить його як повідомлення розробника з вказаним рівнем.

#### Параметри
- **level**: Рівень повідомлення розробника.
- **format**: Форматний рядок.
- **...**: Аргументи для форматування.

#### Повертає
Кількість виведених символів.

### I_DebugPrint
Функція для виведення рядка в лог відлагоджувача.

#### Призначення
Виводить рядок в лог відлагоджувача.

#### Параметри
- **cp**: Рядок для виведення.

### I_DebugPrintf
Функція для форматованого виведення в лог відлагоджувача.

#### Призначення
Форматує рядок та виводить його в лог відлагоджувача.

#### Параметри
- **fmt**: Форматний рядок.
- **...**: Аргументи для форматування.

### batchrun
Глобальна змінна, що вказує, чи потрібно вимкнути виведення, що не є помилками.

#### Призначення
Якщо встановлено в `true`, то виведення, що не є помилками, буде вимкнено.

## Зв'язки з іншими модулями
Файл `printf.h` використовується багатьма підсистемами гри для виведення тексту, повідомлень про помилки та відлагоджувальної інформації. Він забезпечує єдиний інтерфейс для форматованого виведення тексту з різними рівнями виведення та кольоровим форматуванням.

Функції, визначені в цьому файлі, використовуються для:
- Виведення повідомлень про помилки та попередження.
- Виведення повідомлень про події в грі (підбирання предметів, смерть тощо).
- Виведення повідомлень чату.
- Виведення відлагоджувальної інформації.
- Запису інформації в лог-файл.

Файл використовує бібліотеку `stb_sprintf` для форматування рядків, що забезпечує сумісність з функцією `printf` зі стандартної бібліотеки C, але з додатковими можливостями та оптимізаціями.
