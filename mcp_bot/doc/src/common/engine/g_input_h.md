# g_input.h

## Призначення файлу
Файл `g_input.h` визначає платформо-незалежні функції для роботи з введенням користувача, такі як робота з буфером обміну, керування захопленням миші та обробка подій введення.

## Короткий опис
Цей файл містить оголошення функцій, які раніше були частиною `i_input.h`, але були виділені в окремий платформо-незалежний файл, щоб уникнути проблем, пов'язаних з включенням платформо-специфічних даних на Windows. Функції забезпечують роботу з буфером обміну, керування захопленням миші та обробку подій введення.

## Структура файлу
```cpp
#pragma once

// These were in i_input.h, which differed between platforms and on Windows caused problems with its 
// inclusion of system specific data, so it has been separated into this platform independent file.
void I_PutInClipboard (const char *str);
FString I_GetFromClipboard (bool use_primary_selection);
void I_SetMouseCapture();
void I_ReleaseMouseCapture();
void I_GetEvent();
```

## Основні сутності

### I_PutInClipboard
Функція для розміщення тексту в буфері обміну.

#### Призначення
Копіює вказаний рядок у системний буфер обміну.

#### Параметри
- **str**: Вказівник на рядок, який потрібно скопіювати в буфер обміну.

#### Зв'язки з іншими модулями
Використовується різними частинами інтерфейсу користувача для забезпечення можливості копіювання тексту в буфер обміну.

### I_GetFromClipboard
Функція для отримання тексту з буфера обміну.

#### Призначення
Отримує текст із системного буфера обміну.

#### Параметри
- **use_primary_selection**: Логічне значення, що вказує, чи використовувати первинний буфер виділення (актуально для X11 на Unix-подібних системах).

#### Повертає
Об'єкт `FString`, що містить текст з буфера обміну.

#### Зв'язки з іншими модулями
Використовується різними частинами інтерфейсу користувача для забезпечення можливості вставки тексту з буфера обміну.

### I_SetMouseCapture
Функція для захоплення миші.

#### Призначення
Захоплює мишу, обмежуючи її рух в межах вікна гри та приховуючи курсор.

#### Зв'язки з іншими модулями
Використовується системою введення для забезпечення правильної роботи миші в грі, особливо в режимі повного екрану або при використанні миші для керування камерою.

### I_ReleaseMouseCapture
Функція для звільнення захоплення миші.

#### Призначення
Звільняє захоплення миші, дозволяючи їй вільно рухатися по екрану та відновлюючи видимість курсора.

#### Зв'язки з іншими модулями
Використовується системою введення для відновлення нормальної роботи миші при виході з гри, переході в меню або при перемиканні між вікнами.

### I_GetEvent
Функція для отримання подій введення.

#### Призначення
Отримує події введення з системи (клавіатура, миша, джойстик тощо) та передає їх системі обробки подій гри.

#### Зв'язки з іншими модулями
Використовується основним циклом гри для отримання та обробки подій введення користувача. Тісно пов'язана з системою обробки подій, визначеною в `d_event.h`.
