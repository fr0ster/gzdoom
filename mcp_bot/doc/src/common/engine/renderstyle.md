# renderstyle.cpp

## Призначення файлу
Файл `renderstyle.cpp` містить реалізацію стилів рендерингу, які визначають, як об'єкти відображаються в грі, включаючи прозорість, змішування кольорів та спеціальні ефекти.

## Короткий опис
Цей файл реалізує систему стилів рендерингу, яка дозволяє гнучко налаштовувати відображення об'єктів у грі. Він містить визначення стандартних стилів рендерингу, функції для роботи з прозорістю та методи для перевірки видимості об'єктів з урахуванням їх стилю рендерингу та альфа-значення.

## Структура файлу
Файл містить:
1. Консольні змінні для керування відображенням прозорих об'єктів
2. Масив стандартних стилів рендерингу
3. Функцію для обчислення альфа-значення
4. Методи класу `FRenderStyle` для роботи зі стилями рендерингу

## Основні сутності

### Консольні змінні
```cpp
CVAR (Bool, r_drawtrans, true, 0)
CVAR (Int, r_drawfuzz, 1, CVAR_ARCHIVE)
```

#### Призначення
- **r_drawtrans**: Керує відображенням прозорих об'єктів. Якщо встановлено в `false`, прозорі об'єкти не відображаються.
- **r_drawfuzz**: Керує методом відображення розмитих (fuzzy) об'єктів. Значення 0 використовує адитивне змішування, 1 використовує стандартний ефект розмиття, 2 використовує ефект тіні.

### Масив стандартних стилів рендерингу
```cpp
FRenderStyle LegacyRenderStyles[STYLE_Count] = { ... };
```

#### Призначення
Цей масив містить визначення стандартних стилів рендерингу, які використовуються в грі. Кожен стиль має свої параметри операції змішування, джерела альфа-значення, призначення альфа-значення та прапорці.

#### Стилі рендерингу
- **STYLE_None**: Не відображати об'єкт.
- **STYLE_Normal**: Звичайне відображення без прозорості.
- **STYLE_Fuzzy**: Розмитий ефект (використовується для невидимих об'єктів).
- **STYLE_SoulTrans**: Напівпрозорий ефект для душ.
- **STYLE_OptFuzzy**: Оптимізований розмитий ефект, який може перемикатися на адитивне змішування.
- **STYLE_Stencil**: Стиль трафарету з фіксованим кольором.
- **STYLE_Translucent**: Напівпрозорий стиль.
- **STYLE_Add**: Адитивне змішування.
- **STYLE_Shaded**: Затінений стиль з використанням червоного каналу як альфа.
- **STYLE_TranslucentStencil**: Напівпрозорий трафарет.
- **STYLE_Shadow**: Ефект тіні.
- **STYLE_Subtract**: Віднімання кольорів.
- **STYLE_AddStencil**: Адитивний трафарет.
- **STYLE_AddShaded**: Адитивний затінений стиль.
- **STYLE_Multiply**: Множення кольорів.
- **STYLE_InverseMultiply**: Обернене множення кольорів.
- **STYLE_ColorBlend**: Змішування кольорів.
- **STYLE_Source**: Використання тільки джерела.
- **STYLE_ColorAdd**: Додавання кольорів.

### Функція GetAlpha
```cpp
double GetAlpha(int type, double alpha)
{
    switch (type)
    {
    case STYLEALPHA_Zero:       return 0;
    case STYLEALPHA_One:        return 1.;
    case STYLEALPHA_Src:        return alpha;
    case STYLEALPHA_InvSrc:     return 1. - alpha;
    default:                    return 0.5;  // undeterminable
    }
}
```

#### Призначення
Функція `GetAlpha` обчислює фактичне альфа-значення на основі типу альфа-змішування та вхідного альфа-значення.

#### Параметри
- **type**: Тип альфа-змішування (STYLEALPHA_Zero, STYLEALPHA_One, STYLEALPHA_Src, STYLEALPHA_InvSrc).
- **alpha**: Вхідне альфа-значення.

#### Повертає
Обчислене альфа-значення.

### Метод FRenderStyle::IsVisible
```cpp
bool FRenderStyle::IsVisible(double alpha) const throw()
{
    if (BlendOp == STYLEOP_None)
    {
        return false;
    }
    if (BlendOp == STYLEOP_Add || BlendOp == STYLEOP_RevSub)
    {
        if (Flags & STYLEF_Alpha1)
        {
            alpha = 1.;
        }
        else
        {
            alpha = clamp(alpha, 0., 1.);
        }
        return GetAlpha(SrcAlpha, alpha) != 0 || GetAlpha(DestAlpha, alpha) != 1;
    }
    // Treat anything else as visible.
    return true;
}
```

#### Призначення
Метод `IsVisible` перевіряє, чи буде об'єкт видимим з урахуванням його стилю рендерингу та альфа-значення.

#### Параметри
- **alpha**: Альфа-значення об'єкта.

#### Повертає
`true`, якщо об'єкт буде видимим, `false` в іншому випадку.

#### Особливості реалізації
- Якщо операція змішування - `STYLEOP_None`, об'єкт завжди невидимий.
- Для операцій `STYLEOP_Add` та `STYLEOP_RevSub` видимість залежить від альфа-значень джерела та призначення.
- Для інших операцій об'єкт вважається видимим.

### Метод FRenderStyle::CheckFuzz
```cpp
void FRenderStyle::CheckFuzz()
{
    switch (BlendOp)
    {
    default:
        return;

    case STYLEOP_FuzzOrAdd:
        if (r_drawtrans && r_drawfuzz == 0)
        {
            BlendOp = STYLEOP_Add;
            return;
        }
        break;

    case STYLEOP_FuzzOrSub:
        if (r_drawtrans && r_drawfuzz == 0)
        {
            BlendOp = STYLEOP_Sub;
            return;
        }
        break;

    case STYLEOP_FuzzOrRevSub:
        if (r_drawtrans && r_drawfuzz == 0)
        {
            BlendOp = STYLEOP_RevSub;
            return;
        }
        break;
    }

    if (r_drawfuzz == 2)
    {
        BlendOp = STYLEOP_Shadow;
    }
    else
    {
        BlendOp = STYLEOP_Fuzz;
    }
}
```

#### Призначення
Метод `CheckFuzz` коригує операцію змішування на основі консольних змінних `r_drawtrans` та `r_drawfuzz`.

#### Особливості реалізації
- Для операцій `STYLEOP_FuzzOrAdd`, `STYLEOP_FuzzOrSub` та `STYLEOP_FuzzOrRevSub` вибирається відповідна операція на основі значень консольних змінних.
- Якщо `r_drawfuzz` дорівнює 2, використовується ефект тіні (`STYLEOP_Shadow`).
- В іншому випадку використовується стандартний ефект розмиття (`STYLEOP_Fuzz`).

## Зв'язки з іншими модулями
Файл `renderstyle.cpp` пов'язаний з системою рендерингу гри та визначає, як об'єкти відображаються на екрані. Він використовується різними частинами гри для налаштування відображення об'єктів, включаючи спрайти, моделі та інші візуальні елементи.

Цей файл тісно пов'язаний з `renderstyle.h`, який містить оголошення класів та структур, реалізованих у цьому файлі. Він також використовує консольні змінні з `c_cvars.h` для керування відображенням об'єктів.

Стилі рендерингу, визначені в цьому файлі, використовуються системою рендерингу для визначення, як змішувати кольори об'єктів з фоном та іншими об'єктами, що дозволяє створювати різні візуальні ефекти, такі як прозорість, адитивне змішування, множення кольорів та інші.
