# v_colortables.cpp

## Призначення файлу
Файл `v_colortables.cpp` містить реалізацію таблиць кольорів та функцій для змішування кольорів, які використовуються для програмного рендерингу та композиції текстур у грі.

## Короткий опис
Цей файл реалізує таблиці кольорів та функцію для їх побудови, які використовуються для ефективного змішування кольорів у програмному рендерері. Таблиці дозволяють швидко перетворювати кольори з палітри в RGB-формат та виконувати операції змішування без необхідності виконувати складні обчислення під час рендерингу.

## Структура файлу
Файл містить:
1. Оголошення глобальних таблиць кольорів
2. Функцію `BuildTransTable` для побудови таблиць змішування кольорів

## Основні сутності

### Глобальні таблиці кольорів
```cpp
uint32_t Col2RGB8[65][256];
uint32_t *Col2RGB8_LessPrecision[65];
uint32_t Col2RGB8_Inverse[65][256];
uint32_t Col2RGB8_2[63][256];
ColorTable32k RGB32k;
ColorTable256k RGB256k;
```

#### Призначення
- **Col2RGB8**: Таблиця для перетворення індексів палітри в RGB-формат з урахуванням рівня прозорості (65 рівнів).
- **Col2RGB8_LessPrecision**: Масив вказівників на таблиці з меншою точністю для оптимізації.
- **Col2RGB8_Inverse**: Інвертована таблиця для спеціальних ефектів.
- **Col2RGB8_2**: Таблиця з меншою точністю для оптимізації.
- **RGB32k**: Таблиця для швидкого пошуку найближчого кольору в палітрі для RGB555 формату.
- **RGB256k**: Таблиця для швидкого пошуку найближчого кольору в палітрі для RGB666 формату.

#### Призначення
Функція `BuildTransTable` будує таблиці, необхідні для змішування кольорів, які використовуються програмним рендерером та при композиції текстур.

#### Параметри
- **palette**: Вказівник на палітру кольорів, яка використовується для побудови таблиць.

#### Особливості реалізації
Функція виконує наступні кроки:

1. Створює таблицю RGB32k для швидкого пошуку найближчого кольору в палітрі для RGB555 формату:
   ```cpp
   for (r = 0; r < 32; r++)
       for (g = 0; g < 32; g++)
           for (b = 0; b < 32; b++)
               RGB32k.RGB[r][g][b] = ColorMatcher.Pick((r<<3)|(r>>2), (g<<3)|(g>>2), (b<<3)|(b>>2));
   ```

2. Створює таблицю RGB256k для швидкого пошуку найближчого кольору в палітрі для RGB666 формату:
   ```cpp
   for (r = 0; r < 64; r++)
       for (g = 0; g < 64; g++)
           for (b = 0; b < 64; b++)
               RGB256k.RGB[r][g][b] = ColorMatcher.Pick((r<<2)|(r>>4), (g<<2)|(g>>4), (b<<2)|(b>>4));
   ```

3. Створює "swizzled" палітру для швидкого змішування кольорів:
   ```cpp
   for (x = 0; x < 65; x++)
       for (y = 0; y < 256; y++)
           Col2RGB8[x][y] = (((palette[y].r*x)>>4)<<20) |
           ((palette[y].g*x)>>4) |
           (((palette[y].b*x)>>4)<<10);
   ```

4. Створює "swizzled" палітру з меншою точністю для оптимізації:
   ```cpp
   for (x = 1; x < 64; x++)
   {
       Col2RGB8_LessPrecision[x] = Col2RGB8_2[x-1];
       for (y = 0; y < 256; y++)
       {
           Col2RGB8_2[x-1][y] = Col2RGB8[x][y] & 0x3feffbff;
       }
   }
   Col2RGB8_LessPrecision[0] = Col2RGB8[0];
   Col2RGB8_LessPrecision[64] = Col2RGB8[64];
   ```

5. Створює інвертовану "swizzled" палітру для спеціальних ефектів:
   ```cpp
   for (x = 0; x < 65; x++)
       for (y = 0; y < 256; y++)
       {
           Col2RGB8_Inverse[x][y] = (((((255-palette[y].r)*x)>>4)<<20) |
                                    (((255-palette[y].g)*x)>>4) |
                                    ((((255-palette[y].b)*x)>>4)<<10)) & 0x3feffbff;
       }
   ```

## Зв'язки з іншими модулями
Файл `v_colortables.cpp` пов'язаний з системою рендерингу гри та забезпечує ефективне змішування кольорів для програмного рендерера. Він використовується для:

- Програмного рендерингу графіки
- Композиції текстур
- Спеціальних ефектів, таких як прозорість та інверсія кольорів

Цей файл тісно пов'язаний з `v_colortables.h`, який містить оголошення структур та функцій, реалізованих у цьому файлі. Він також використовує `colormatcher.h` для пошуку найближчого кольору в палітрі.

Таблиці кольорів, визначені в цьому файлі, використовуються різними частинами системи рендерингу для ефективного змішування кольорів без необхідності виконувати складні обчислення під час рендерингу.
