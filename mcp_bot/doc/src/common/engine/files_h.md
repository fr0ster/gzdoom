# files.h

## Призначення файлу
Файл `files.h` є заголовочним файлом, який надає зручний інтерфейс для роботи з файловою системою. Він імпортує та використовує класи з `fs_files.h` з простору імен FileSys.

## Короткий опис
Цей файл є простою обгорткою (wrapper) для файлової системи GZDoom. Він імпортує класи `FileReader`, `FileWriter` та `BufferWriter` з простору імен FileSys та робить їх доступними в глобальному просторі імен для зручності використання в інших частинах коду.

## Структура файлу
```cpp
#pragma once
#include "fs_files.h"

using FileSys::FileReader;
using FileSys::FileWriter;
using FileSys::BufferWriter;
```

## Основні сутності

### FileReader
Клас для читання даних з файлів або блоків пам'яті.

#### Призначення
Надає інтерфейс для читання даних з різних джерел (файли, пам'ять).

#### Інтерфейс
- Методи для відкриття файлів та блоків пам'яті
- Методи для читання даних різних типів
- Методи для навігації по файлу (Seek, Tell)

#### Зв'язки з іншими модулями
Використовується багатьма модулями для завантаження ресурсів, конфігурацій та інших даних.

### FileWriter
Клас для запису даних у файли.

#### Призначення
Надає інтерфейс для запису даних у файли.

#### Інтерфейс
- Методи для відкриття файлів для запису
- Методи для запису даних
- Методи для навігації по файлу (Seek, Tell)

#### Зв'язки з іншими модулями
Використовується для збереження конфігурацій, логів та інших даних.

### BufferWriter
Підклас FileWriter, який записує дані в буфер пам'яті замість файлу.

#### Призначення
Дозволяє формувати дані в пам'яті перед записом у файл або передачею по мережі.

#### Інтерфейс
- Методи для запису даних у внутрішній буфер
- Методи для отримання сформованого буфера

#### Зв'язки з іншими модулями
Використовується для формування даних, які потім можуть бути збережені або передані.

## Реалізація
Файл не містить власної реалізації, а лише імпортує класи з `fs_files.h` та робить їх доступними через using-директиви.
