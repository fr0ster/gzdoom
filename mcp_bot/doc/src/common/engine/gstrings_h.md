# gstrings.h

## Призначення файлу
Файл `gstrings.h` оголошує глобальну таблицю рядків `GStrings`, яка використовується для локалізації та управління текстовими рядками в грі.

## Короткий опис
Цей файл містить оголошення глобальної змінної `GStrings` типу `FStringTable`, яка використовується для зберігання та доступу до локалізованих текстових рядків гри. Також файл оголошує масив `endmsg`, який містить повідомлення, що відображаються в кінці гри.

## Структура файлу
```cpp
#ifndef __GSTRINGS_H__
#define __GSTRINGS_H__

#ifdef _MSC_VER
#pragma once
#endif

#include "stringtable.h"

extern FStringTable GStrings;

extern const char *endmsg[];

#endif //__GSTRINGS_H__
```

## Основні сутності

### GStrings
Глобальна змінна типу `FStringTable`, яка зберігає всі локалізовані рядки гри.

#### Призначення
Надає доступ до локалізованих текстових рядків з будь-якої частини коду. Використовується для відображення тексту інтерфейсу, повідомлень, назв предметів, опису зброї тощо в різних мовах.

#### Інтерфейс
Через змінну `GStrings` доступні всі методи класу `FStringTable`:
- `LoadStrings`: Завантажує рядки з файлової системи для вказаної мови.
- `UpdateLanguage`: Оновлює активну мову.
- `GetString`: Отримує локалізований рядок за його ім'ям.
- `localize`: Локалізує рядок, якщо він починається з символу '$'.
- Інші методи для роботи з локалізованими рядками.

#### Реалізація
`GStrings` використовує клас `FStringTable`, який реалізує систему локалізації. Рядки зберігаються в таблицях, індексованих за ідентифікаторами мов та іменами рядків. Підтримується також система макросів для заміни частин рядків.

#### Зв'язки з іншими модулями
`GStrings` використовується практично всіма модулями, які відображають текст користувачеві, включаючи інтерфейс, меню, повідомлення, опис предметів тощо.

### endmsg
Масив рядків, що містить повідомлення, які відображаються в кінці гри.

#### Призначення
Зберігає різні повідомлення, які можуть бути показані гравцеві після завершення гри.

#### Зв'язки з іншими модулями
Використовується кодом, який відповідає за відображення фінального екрану гри.
