# date.cpp

## Призначення файлу
Файл `date.cpp` містить функції для роботи з датою та часом, а також експортує їх для використання в скриптовій мові гри.

## Короткий опис
Цей файл реалізує функціональність для отримання та встановлення поточної дати та часу, а також для форматування часових значень. Він включає консольні команди для встановлення та отримання дати, а також функції, які експортуються в віртуальну машину скриптової мови.

## Структура файлу
Файл містить:
1. Глобальну змінну `epochoffset` для зміщення епохи
2. Консольні команди `setdate` та `getdate` для встановлення та отримання дати
3. Допоміжні функції для роботи з часом
4. Експорт функцій в віртуальну машину скриптової мови

## Основні сутності

### Глобальна змінна epochoffset
```cpp
time_t epochoffset = 0;    // epoch start in seconds (0 = January 1st, 1970)
```

#### Призначення
Змінна `epochoffset` використовується для зміщення початку епохи в секундах. За замовчуванням епоха починається 1 січня 1970 року (Unix-час), але ця змінна дозволяє змінити цю точку відліку.

### Консольна команда setdate
```cpp
UNSAFE_CCMD(setdate)
{
    // ...
}
```

#### Призначення
Консольна команда `setdate` дозволяє встановити поточну дату та час. Вона приймає два параметри: час у форматі HH:MM:SS та дату у форматі DD-MM-YYYY.

#### Параметри
- **HH:MM:SS**: Час у форматі години:хвилини:секунди.
- **DD-MM-YYYY**: Дата у форматі день-місяць-рік.

#### Особливості реалізації
- Команда розбиває вхідні параметри на компоненти та перевіряє їх коректність.
- Встановлює нову дату та час, обчислюючи зміщення епохи.
- Враховує особливості роботи з літнім часом (DST), коригуючи зміщення за потреби.

### Консольна команда getdate
```cpp
CCMD(getdate)
{
    // ...
}
```

#### Призначення
Консольна команда `getdate` виводить поточну дату та час з урахуванням зміщення епохи.

#### Особливості реалізації
- Отримує поточний час та додає до нього зміщення епохи.
- Форматує дату та час у вигляді рядка та виводить його.

### Функція GetEpochTime
```cpp
static int GetEpochTime()
{
    time_t now;
    time(&now);
    return now != (time_t)(-1) ? int(now + epochoffset) : -1;
}
```

#### Призначення
Функція `GetEpochTime` повертає поточний час у секундах з початку епохи з урахуванням зміщення.

#### Повертає
Поточний час у секундах з початку епохи або -1 у випадку помилки.

### Функція CheckStrfString
```cpp
static FString CheckStrfString(FString timeForm)
{
    // ...
}
```

#### Призначення
Функція `CheckStrfString` перевіряє коректність рядка формату для функції `strftime`.

#### Параметри
- **timeForm**: Рядок формату для перевірки.

#### Повертає
Порожній рядок, якщо формат коректний, або проблемний токен, якщо формат некоректний.

#### Особливості реалізації
- Перевіряє, чи всі специфікатори формату (%x) є допустимими.
- Обробляє спеціальні випадки, такі як %% (літерал %).

### Функція FormatTime
```cpp
static void FormatTime(const FString& timeForm, int timeVal, FString* result)
{
    // ...
}
```

#### Призначення
Функція `FormatTime` форматує часове значення згідно з вказаним форматом.

#### Параметри
- **timeForm**: Рядок формату для функції `strftime`.
- **timeVal**: Часове значення в секундах з початку епохи.
- **result**: Вказівник на рядок, в який буде записано результат.

#### Особливості реалізації
- Перевіряє коректність рядка формату за допомогою функції `CheckStrfString`.
- Використовує функцію `strftime` для форматування часу.
- Викидає виняток, якщо формат некоректний.

### Експорт функцій в віртуальну машину
```cpp
DEFINE_ACTION_FUNCTION_NATIVE(_SystemTime, Now, GetEpochTime)
{
    PARAM_PROLOGUE;
    ACTION_RETURN_INT(GetEpochTime());
}

DEFINE_ACTION_FUNCTION_NATIVE(_SystemTime, Format, FormatTime)
{
    PARAM_PROLOGUE;
    PARAM_STRING(timeForm);
    PARAM_INT(timeVal);
    FString result;
    FormatTime(timeForm, timeVal, &result);
    ACTION_RETURN_STRING(result);
}
```

#### Призначення
Ці функції експортують функціональність роботи з часом в віртуальну машину скриптової мови.

#### Функції
- **_SystemTime.Now()**: Повертає поточний час у секундах з початку епохи.
- **_SystemTime.Format(timeForm, timeVal)**: Форматує часове значення згідно з вказаним форматом.

## Зв'язки з іншими модулями
Файл `date.cpp` пов'язаний з системою консольних команд та віртуальною машиною скриптової мови. Він надає функціональність для роботи з датою та часом, яка може бути використана як через консольні команди, так і через скриптову мову.

Консольні команди `setdate` та `getdate` дозволяють користувачу встановлювати та отримувати дату та час, а функції `_SystemTime.Now()` та `_SystemTime.Format()` надають доступ до цієї функціональності з скриптової мови.

Файл також використовує стандартну бібліотеку C для роботи з часом (`time.h`), а також внутрішні модулі гри для роботи з рядками та віртуальною машиною.
