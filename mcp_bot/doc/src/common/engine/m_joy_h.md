# m_joy.h

## Призначення файлу
Файл `m_joy.h` визначає інтерфейси та функції для роботи з джойстиками та іншими ігровими контролерами.

## Короткий опис
Цей файл містить визначення перелічення осей джойстика, інтерфейс для конфігурації джойстика, а також функції для завантаження та збереження конфігурацій, генерації подій кнопок та обробки осей джойстика. Файл забезпечує абстракцію для роботи з різними типами контролерів на різних платформах.

## Структура файлу
```cpp
#ifndef M_JOY_H
#define M_JOY_H

#include "basics.h"
#include "tarray.h"
#include "c_cvars.h"

enum EJoyAxis
{
    JOYAXIS_None = -1,
    JOYAXIS_Yaw,
    JOYAXIS_Pitch,
    JOYAXIS_Forward,
    JOYAXIS_Side,
    JOYAXIS_Up,
//    JOYAXIS_Roll,        // Ha ha. No roll for you.
    NUM_JOYAXIS,
};

// Generic configuration interface for a controller.
struct IJoystickConfig
{
    virtual ~IJoystickConfig() = 0;

    virtual FString GetName() = 0;
    virtual float GetSensitivity() = 0;
    virtual void SetSensitivity(float scale) = 0;

    virtual int GetNumAxes() = 0;
    virtual float GetAxisDeadZone(int axis) = 0;
    virtual EJoyAxis GetAxisMap(int axis) = 0;
    virtual const char *GetAxisName(int axis) = 0;
    virtual float GetAxisScale(int axis) = 0;

    virtual void SetAxisDeadZone(int axis, float zone) = 0;
    virtual void SetAxisMap(int axis, EJoyAxis gameaxis) = 0;
    virtual void SetAxisScale(int axis, float scale) = 0;

    virtual bool GetEnabled() = 0;
    virtual void SetEnabled(bool enabled) = 0;

    virtual bool AllowsEnabledInBackground() = 0;
    virtual bool GetEnabledInBackground() = 0;
    virtual void SetEnabledInBackground(bool enabled) = 0;

    virtual bool IsSensitivityDefault() = 0;
    virtual bool IsAxisDeadZoneDefault(int axis) = 0;
    virtual bool IsAxisMapDefault(int axis) = 0;
    virtual bool IsAxisScaleDefault(int axis) = 0;

    virtual void SetDefaultConfig() = 0;
    virtual FString GetIdentifier() = 0;
};

EXTERN_CVAR(Bool, use_joystick);

bool M_LoadJoystickConfig(IJoystickConfig *joy);
void M_SaveJoystickConfig(IJoystickConfig *joy);

void Joy_GenerateButtonEvents(int oldbuttons, int newbuttons, int numbuttons, int base);
void Joy_GenerateButtonEvents(int oldbuttons, int newbuttons, int numbuttons, const int *keys);
int Joy_XYAxesToButtons(double x, double y);
double Joy_RemoveDeadZone(double axisval, double deadzone, uint8_t *buttons);

// These ought to be provided by a system-specific i_input.cpp.
void I_GetAxes(float axes[NUM_JOYAXIS]);
void I_GetJoysticks(TArray<IJoystickConfig *> &sticks);
IJoystickConfig *I_UpdateDeviceList();
extern void UpdateJoystickMenu(IJoystickConfig *);

#endif
```

## Основні сутності

### EJoyAxis
Перелічення, що визначає осі джойстика, які використовуються в грі.

#### Призначення
Визначає стандартні осі джойстика, які можуть бути призначені для різних дій у грі.

#### Значення
- **JOYAXIS_None**: Відсутня вісь (значення -1).
- **JOYAXIS_Yaw**: Вісь повороту (зазвичай горизонтальний рух).
- **JOYAXIS_Pitch**: Вісь нахилу (зазвичай вертикальний рух).
- **JOYAXIS_Forward**: Вісь руху вперед/назад.
- **JOYAXIS_Side**: Вісь руху вліво/вправо.
- **JOYAXIS_Up**: Вісь руху вгору/вниз.
- **NUM_JOYAXIS**: Кількість осей (використовується для визначення розміру масивів).

#### Зв'язки з іншими модулями
Використовується системою введення для відображення фізичних осей джойстика на дії в грі.

### IJoystickConfig
Інтерфейс для конфігурації джойстика.

#### Призначення
Визначає загальний інтерфейс для конфігурації джойстика, який може бути реалізований для різних типів контролерів на різних платформах.

#### Методи
- **~IJoystickConfig**: Віртуальний деструктор.
- **GetName**: Повертає ім'я джойстика.
- **GetSensitivity**: Повертає чутливість джойстика.
- **SetSensitivity**: Встановлює чутливість джойстика.
- **GetNumAxes**: Повертає кількість осей джойстика.
- **GetAxisDeadZone**: Повертає мертву зону для вказаної осі.
- **GetAxisMap**: Повертає відображення фізичної осі на ігрову вісь.
- **GetAxisName**: Повертає назву вказаної осі.
- **GetAxisScale**: Повертає масштаб для вказаної осі.
- **SetAxisDeadZone**: Встановлює мертву зону для вказаної осі.
- **SetAxisMap**: Встановлює відображення фізичної осі на ігрову вісь.
- **SetAxisScale**: Встановлює масштаб для вказаної осі.
- **GetEnabled**: Повертає стан увімкнення джойстика.
- **SetEnabled**: Встановлює стан увімкнення джойстика.
- **AllowsEnabledInBackground**: Перевіряє, чи джойстик може бути увімкнений у фоновому режимі.
- **GetEnabledInBackground**: Повертає стан увімкнення джойстика у фоновому режимі.
- **SetEnabledInBackground**: Встановлює стан увімкнення джойстика у фоновому режимі.
- **IsSensitivityDefault**: Перевіряє, чи чутливість джойстика встановлена за замовчуванням.
- **IsAxisDeadZoneDefault**: Перевіряє, чи мертва зона для вказаної осі встановлена за замовчуванням.
- **IsAxisMapDefault**: Перевіряє, чи відображення для вказаної осі встановлене за замовчуванням.
- **IsAxisScaleDefault**: Перевіряє, чи масштаб для вказаної осі встановлений за замовчуванням.
- **SetDefaultConfig**: Встановлює конфігурацію джойстика за замовчуванням.
- **GetIdentifier**: Повертає унікальний ідентифікатор джойстика.

#### Зв'язки з іншими модулями
Використовується системою введення для конфігурації та використання джойстиків.

### use_joystick
Консольна змінна, що визначає, чи використовувати джойстик.

#### Призначення
Дозволяє вмикати або вимикати використання джойстика в грі через консольні команди або меню налаштувань.

#### Зв'язки з іншими модулями
Використовується системою введення для визначення, чи потрібно обробляти введення з джойстика.

### M_LoadJoystickConfig
Функція для завантаження конфігурації джойстика.

#### Призначення
Завантажує збережену конфігурацію для вказаного джойстика.

#### Параметри
- **joy**: Вказівник на об'єкт конфігурації джойстика.

#### Повертає
Логічне значення, що вказує на успішність завантаження конфігурації.

#### Зв'язки з іншими модулями
Використовується системою введення для завантаження збережених налаштувань джойстика.

### M_SaveJoystickConfig
Функція для збереження конфігурації джойстика.

#### Призначення
Зберігає поточну конфігурацію вказаного джойстика.

#### Параметри
- **joy**: Вказівник на об'єкт конфігурації джойстика.

#### Зв'язки з іншими модулями
Використовується системою введення для збереження налаштувань джойстика.

### Joy_GenerateButtonEvents
Функція для генерації подій кнопок джойстика.

#### Призначення
Генерує події натискання та відпускання кнопок джойстика на основі зміни стану кнопок.

#### Параметри (перша перевантажена версія)
- **oldbuttons**: Попередній стан кнопок.
- **newbuttons**: Новий стан кнопок.
- **numbuttons**: Кількість кнопок.
- **base**: Базовий індекс для кнопок.

#### Параметри (друга перевантажена версія)
- **oldbuttons**: Попередній стан кнопок.
- **newbuttons**: Новий стан кнопок.
- **numbuttons**: Кількість кнопок.
- **keys**: Масив кодів клавіш, які відповідають кнопкам.

#### Зв'язки з іншими модулями
Використовується системою введення для генерації подій кнопок джойстика, які потім обробляються системою обробки подій.

### Joy_XYAxesToButtons
Функція для перетворення значень осей X та Y на події кнопок.

#### Призначення
Перетворює значення осей X та Y на події кнопок, що дозволяє використовувати аналогові осі як цифрові кнопки.

#### Параметри
- **x**: Значення осі X.
- **y**: Значення осі Y.

#### Повертає
Бітова маска, що представляє натиснуті кнопки.

#### Зв'язки з іншими модулями
Використовується системою введення для емуляції кнопок за допомогою аналогових осей.

### Joy_RemoveDeadZone
Функція для видалення мертвої зони з значення осі.

#### Призначення
Видаляє мертву зону з значення осі та нормалізує результат.

#### Параметри
- **axisval**: Значення осі.
- **deadzone**: Розмір мертвої зони.
- **buttons**: Вказівник на масив кнопок, який може бути оновлений на основі значення осі.

#### Повертає
Нормалізоване значення осі без мертвої зони.

#### Зв'язки з іншими модулями
Використовується системою введення для обробки значень осей джойстика.

### I_GetAxes

#### Призначення

#### Параметри

#### Призначення
