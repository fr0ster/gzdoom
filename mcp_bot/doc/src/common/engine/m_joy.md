# m_joy.cpp

## Призначення файлу
Файл `m_joy.cpp` містить реалізацію функцій для роботи з джойстиками та геймпадами в грі, включаючи конфігурацію, обробку введення та генерацію подій.

## Короткий опис
Цей файл реалізує систему для роботи з джойстиками, яка дозволяє налаштовувати осі та кнопки, зберігати та завантажувати конфігурацію, а також перетворювати введення з джойстика в події гри. Він також містить функції для обробки мертвих зон (deadzone) та масштабування осей.

## Структура файлу
Файл містить:
1. Реалізацію віртуального деструктора для інтерфейсу `IJoystickConfig`
2. Функції для завантаження та збереження конфігурації джойстика
3. Функції для обробки введення з джойстика
4. Функції для генерації подій кнопок

## Основні сутності

### Глобальні змінні та константи
```cpp
EXTERN_CVAR(Bool, joy_ps2raw)
EXTERN_CVAR(Bool, joy_dinput)
EXTERN_CVAR(Bool, joy_xinput)

CUSTOM_CVARD(Bool, use_joystick, false, CVAR_ARCHIVE|CVAR_GLOBALCONFIG|CVAR_NOINITCALL, "enables input from the joystick if it is present") 
{
#ifdef _WIN32
    joy_ps2raw->Callback();
    joy_dinput->Callback();
    joy_xinput->Callback();
#endif
}

static uint8_t JoyAngleButtons[8] = { 1, 1+4, 4, 2+4, 2, 2+8, 8, 1+8 };
```

#### Призначення
- **joy_ps2raw**: Консольна змінна для включення/виключення підтримки PS2-контролерів.
- **joy_dinput**: Консольна змінна для включення/виключення підтримки DirectInput.
- **joy_xinput**: Консольна змінна для включення/виключення підтримки XInput.
- **use_joystick**: Консольна змінна для включення/виключення підтримки джойстиків в цілому.
- **JoyAngleButtons**: Масив, який визначає, які кнопки відповідають різним напрямкам аналогового стіка.

### Функція M_SetJoystickConfigSection
```cpp
static bool M_SetJoystickConfigSection(IJoystickConfig *joy, bool create, FConfigFile* GameConfig)
{
    FString id = "Joy:";
    id += joy->GetIdentifier();
    if (!GameConfig) return false;
    return GameConfig->SetSection(id.GetChars(), create);
}
```

#### Призначення
Функція `M_SetJoystickConfigSection` встановлює секцію конфігураційного файлу для читання або запису конфігурації джойстика.

#### Параметри
- **joy**: Вказівник на об'єкт конфігурації джойстика.
- **create**: Прапорець, який вказує, чи створювати секцію, якщо вона не існує.
- **GameConfig**: Вказівник на об'єкт конфігураційного файлу.

#### Повертає
`true`, якщо секція була успішно встановлена, `false` в іншому випадку.

### Функція Joy_RemoveDeadZone
```cpp
double Joy_RemoveDeadZone(double axisval, double deadzone, uint8_t *buttons)
{
    // ...
}
```

#### Призначення
Функція `Joy_RemoveDeadZone` обробляє значення осі джойстика, видаляючи мертву зону.

#### Параметри
- **axisval**: Значення осі (-1.0 до 1.0).
- **deadzone**: Розмір мертвої зони (0.0 до 1.0).
- **buttons**: Вказівник на змінну, в яку буде записано стан кнопок (0 = не натиснуто, 1 = плюс, 2 = мінус).

#### Повертає
Оброблене значення осі з видаленою мертвою зоною.

#### Особливості реалізації
- Якщо значення осі менше за мертву зону, повертає 0.
- В іншому випадку масштабує значення так, щоб мертва зона стала новим нулем.

#### Призначення
Функції `Joy_GenerateButtonEvents` генерують події натискання та відпускання кнопок на основі зміни стану кнопок джойстика.

#### Особливості реалізації
- Порівнює попередній та новий стан кнопок для визначення змін.
- Генерує події `EV_KeyDown` для натиснутих кнопок та `EV_KeyUp` для відпущених кнопок.
- Відправляє події через функцію `D_PostEvent`.
