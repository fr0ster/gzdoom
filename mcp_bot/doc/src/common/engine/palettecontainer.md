# palettecontainer.cpp

## Призначення файлу
Файл `palettecontainer.cpp` містить реалізацію класів для роботи з палітрами кольорів та таблицями трансляції кольорів у грі.

## Короткий опис
Цей файл реалізує функціональність для керування палітрами кольорів, створення та маніпулювання таблицями трансляції кольорів, які використовуються для різних ефектів, таких як зміна кольорів спрайтів, створення спеціальних ефектів (наприклад, лід) та інше. Файл також містить глобальні об'єкти `GPalette` та `ColorMatcher`, які використовуються для роботи з кольорами в грі.

## Структура файлу
Файл містить:
1. Реалізацію методів класу `PaletteContainer`
2. Реалізацію методів класу `FRemapTable`
3. Глобальні об'єкти для роботи з кольорами

## Основні сутності

### Глобальні об'єкти
```cpp
PaletteContainer GPalette;
FColorMatcher ColorMatcher;
extern uint8_t IcePalette[16][3];
```

#### Призначення
- **GPalette**: Глобальний об'єкт, який містить палітру кольорів гри та таблиці трансляції.
- **ColorMatcher**: Об'єкт для пошуку найближчого кольору в палітрі.
- **IcePalette**: Масив кольорів для створення ефекту льоду.

### Клас PaletteContainer

#### Методи
- **Init(int numslots, const uint8_t* indexmap)**: Ініціалізує контейнер палітри з вказаною кількістю слотів для таблиць трансляції.
- **SetPalette(const uint8_t* colors, int transparent_index)**: Встановлює базову палітру кольорів.
- **Clear()**: Очищає всі таблиці трансляції.
- **DetermineTranslucency(FileReader& tranmap)**: Визначає рівень прозорості на основі карти трансляції.
- **AddRemap(FRemapTable* remap)**: Додає таблицю трансляції до контейнера, уникаючи дублікатів.
- **UpdateTranslation(FTranslationID trans, FRemapTable* remap)**: Оновлює існуючу таблицю трансляції.
- **AddTranslation(int slot, FRemapTable* remap, int count)**: Додає нову таблицю трансляції до вказаного слоту.
- **CopyTranslation(FTranslationID dest, FTranslationID src)**: Копіює таблицю трансляції з одного ідентифікатора в інший.
- **TranslationToTable(int translation)**: Повертає таблицю трансляції за її ідентифікатором.
- **StoreTranslation(int slot, FRemapTable *remap)**: Зберігає копію таблиці трансляції, уникаючи дублікатів.
- **GenerateGlobalBrightmapFromColormap(const uint8_t *cmapdata, int numlevels)**: Генерує глобальну карту яскравості на основі карти кольорів.

#### Особливості реалізації
- Клас `PaletteContainer` використовує унікальні таблиці трансляції для економії пам'яті, зберігаючи лише одну копію кожної унікальної таблиці.
- Метод `SetPalette` ініціалізує базову палітру та створює спеціальні таблиці трансляції, такі як `GrayRamp`, `GrayscaleMap` та `IceMap`.
- Метод `DetermineTranslucency` аналізує карту трансляції для визначення рівня прозорості.
- Метод `GenerateGlobalBrightmapFromColormap` аналізує карту кольорів для визначення, які кольори повинні бути завжди яскравими.

### Клас FRemapTable

#### Методи
- **operator==(const FRemapTable& o)**: Порівнює дві таблиці трансляції.
- **MakeIdentity()**: Створює таблицю трансляції, яка не змінює кольори.
- **IsIdentity()**: Перевіряє, чи є таблиця трансляції ідентичною (не змінює кольори).
- **AddIndexRange(int start, int end, int pal1, int pal2)**: Додає діапазон індексів до таблиці трансляції.
- **AddColorRange(int start, int end, int r1, int g1, int b1, int r2, int g2, int b2)**: Додає діапазон кольорів до таблиці трансляції.
- **AddDesaturation(int start, int end, double r1, double g1, double b1, double r2, double g2, double b2)**: Додає десатурацію кольорів до таблиці трансляції.
- **AddColourisation(int start, int end, int r, int g, int b)**: Додає колоризацію до таблиці трансляції.
- **AddTint(int start, int end, int r, int g, int b, int amount)**: Додає відтінок до таблиці трансляції.
- **AddToTranslation(const char *range)**: Додає трансляцію з текстового опису.
- **AddColors(int start, int count, const uint8_t*colors, int trans_color)**: Додає сирі кольори до таблиці трансляції.

#### Особливості реалізації
- Клас `FRemapTable` містить масиви `Remap` та `Palette`, які використовуються для трансляції кольорів.
- Метод `AddIndexRange` додає діапазон індексів до таблиці трансляції, інтерполюючи між початковим та кінцевим індексами.
- Метод `AddColorRange` додає діапазон кольорів до таблиці трансляції, інтерполюючи між початковим та кінцевим кольорами.
- Метод `AddDesaturation` додає десатурацію кольорів до таблиці трансляції, змінюючи насиченість кольорів.
- Метод `AddColourisation` додає колоризацію до таблиці трансляції, зберігаючи яскравість оригінальних кольорів.
- Метод `AddTint` додає відтінок до таблиці трансляції, змішуючи оригінальні кольори з вказаним кольором.
- Метод `AddToTranslation` аналізує текстовий опис трансляції та додає відповідну трансляцію до таблиці.

### Допоміжні функції
```cpp
static bool IndexOutOfRange(const int color);
static bool IndexOutOfRange(const int start, const int end);
static bool IndexOutOfRange(const int start1, const int end1, const int start2, const int end2);
```

#### Призначення
Ці функції перевіряють, чи знаходяться індекси кольорів у допустимому діапазоні (0-255), і виводять попередження, якщо індекси виходять за межі діапазону.

## Зв'язки з іншими модулями
Файл `palettecontainer.cpp` пов'язаний з системою рендерингу та візуальними ефектами гри. Він використовується для:

- Керування палітрою кольорів гри
- Створення та маніпулювання таблицями трансляції кольорів
- Реалізації спеціальних ефектів, таких як лід, прозорість та інші
- Підтримки різних форматів трансляції кольорів, включаючи індексні, RGB та десатурацію

Цей файл тісно пов'язаний з `palettecontainer.h`, який містить оголошення класів та структур, реалізованих у цьому файлі. Він також використовує функціональність з інших модулів, таких як `palutil.h`, `sc_man.h`, `m_crc32.h`, `printf.h`, `colormatcher.h` та `files.h`.
