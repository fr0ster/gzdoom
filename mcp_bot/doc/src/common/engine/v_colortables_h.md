# v_colortables.h

## Призначення файлу
Файл `v_colortables.h` визначає структури та змінні для роботи з таблицями кольорів, які використовуються для ефективного перетворення кольорів та змішування (блендінгу) при рендерингу.

## Короткий опис
Цей файл містить визначення таблиць кольорів, які використовуються для швидкого перетворення між RGB-форматами та індексованими палітрами, а також для ефективного змішування кольорів. Файл був виділений з `v_video.h` для уникнення циклічних залежностей між `v_video.h` та `textures.h`.

## Структура файлу
```cpp
#pragma once

#include <stdint.h>
#include "palentry.h"

// Визначення структур та змінних для таблиць кольорів
union ColorTable32k
{
    uint8_t RGB[32][32][32];
    uint8_t All[32 * 32 * 32];
};
extern ColorTable32k RGB32k;

union ColorTable256k
{
    uint8_t RGB[64][64][64];
    uint8_t All[64 * 64 * 64];
};
extern ColorTable256k RGB256k;

extern uint32_t Col2RGB8[65][256];
extern uint32_t *Col2RGB8_LessPrecision[65];
extern uint32_t Col2RGB8_Inverse[65][256];

void BuildTransTable(const PalEntry *palette);
```

## Основні сутності

### ColorTable32k
Об'єднання (union), що представляє таблицю перетворення кольорів у форматі R5G5B5.

#### Призначення
Забезпечує швидке перетворення кольорів з RGB-формату (з 5 бітами на кожен компонент) в індекси палітри. Використовується для ефективного пошуку найближчого кольору в палітрі.

#### Поля
- **RGB**: Тривимірний масив для доступу до таблиці за компонентами RGB.
- **All**: Одновимірний масив для доступу до всієї таблиці як до лінійного масиву.

#### Особливості реалізації
Використовується об'єднання (union) для можливості "переповнення" без попереджень компілятора. Це дозволяє уникнути помилок під час виконання при використанні санітайзерів, таких як `-fsanitize=bounds` в Clang.

### ColorTable256k
Об'єднання (union), що представляє таблицю перетворення кольорів у форматі RGB666.

#### Призначення
Забезпечує швидке перетворення кольорів з RGB-формату (з 6 бітами на кожен компонент) в індекси палітри. Надає більшу точність кольорів порівняно з ColorTable32k.

#### Поля
- **RGB**: Тривимірний масив для доступу до таблиці за компонентами RGB.
- **All**: Одновимірний масив для доступу до всієї таблиці як до лінійного масиву.

### Col2RGB8
Двовимірний масив, що містить попередньо помножені значення палітри для пошуку кольорів.

#### Призначення
Зберігає палітру в спеціальному форматі R10B10G10 для ефективних обчислень змішування кольорів. Використовується для швидкого змішування кольорів при рендерингу.

#### Формат
- На рівні 64: `--RRRRRrrr--BBBBBbbb--GGGGGggg--`
- На рівні 1: `--------rrrr------bbbb------gggg`

### Col2RGB8_LessPrecision
Масив вказівників на таблиці, аналогічні Col2RGB8, але з меншою точністю.

#### Призначення
Аналогічно Col2RGB8, але молодші біти для червоного та синього компонентів примусово встановлені в нуль, щоб запобігти переповненню в наступний компонент при змішуванні.

#### Формат
- На рівні 64: `--RRRRRrrr-#BBBBBbbb-#GGGGGggg--`
- На рівні 1: `--------rrr#------bbb#------gggg`

### Col2RGB8_Inverse
Двовимірний масив, аналогічний Col2RGB8_LessPrecision, але з інвертованою вихідною палітрою.

#### Призначення
Використовується для спеціальних ефектів, які потребують інвертованих кольорів.

### BuildTransTable
Функція для побудови таблиць перетворення кольорів.

#### Призначення
Ініціалізує таблиці перетворення кольорів на основі заданої палітри.

#### Параметри
- **palette**: Вказівник на масив PalEntry, що містить палітру кольорів.

#### Зв'язки з іншими модулями
Використовується системою рендерингу для ініціалізації таблиць кольорів при зміні палітри.

## Зв'язки з іншими модулями
Таблиці кольорів, визначені в цьому файлі, використовуються системою рендерингу для ефективного перетворення та змішування кольорів. Вони тісно пов'язані з системою палітр та відображення графіки.
