# filesystem.h

## Призначення файлу
Файл `filesystem.h` є заголовочним файлом, який надає зручний інтерфейс для роботи з файловою системою GZDoom. Він імпортує та використовує класи з `fs_filesystem.h` з простору імен FileSys.

## Короткий опис
Цей файл є обгорткою (wrapper) для файлової системи GZDoom. Він імпортує класи `FileSystem` та `FResourceFile` з простору імен FileSys та робить їх доступними в глобальному просторі імен для зручності використання в інших частинах коду. Також він створює глобальний екземпляр класу FileSystem під назвою `fileSystem`.

## Структура файлу
```cpp
#pragma once
#include "fs_filesystem.h"

using FileSys::FileSystem;
using FileSys::FResourceFile;

inline FileSys::FileSystem fileSystem;
```

## Основні сутності

### FileSystem
Клас, що забезпечує доступ до файлової системи GZDoom.

#### Призначення
Надає інтерфейс для роботи з файловою системою, включаючи доступ до WAD-файлів, пошук ресурсів, читання даних тощо.

#### Інтерфейс
- Методи для ініціалізації файлової системи з одного або декількох файлів
- Методи для пошуку ресурсів за ім'ям
- Методи для читання даних з ресурсів
- Методи для отримання інформації про ресурси

#### Реалізація
Клас FileSystem реалізує складну систему індексації та пошуку ресурсів, використовуючи хеш-таблиці для швидкого доступу до ресурсів за ім'ям. Він також підтримує простори імен для організації ресурсів.

#### Зв'язки з іншими модулями
FileSystem є центральним компонентом для доступу до ресурсів гри. Він використовується практично всіма модулями, які потребують доступу до даних гри, таких як текстури, звуки, рівні тощо.

### FResourceFile
Клас, що представляє файл ресурсів (WAD, PK3, тощо).

#### Призначення
Надає інтерфейс для роботи з файлами ресурсів різних форматів.

#### Інтерфейс
- Методи для відкриття та закриття файлів ресурсів
- Методи для доступу до окремих ресурсів у файлі
- Методи для отримання інформації про файл ресурсів

#### Зв'язки з іншими модулями
Використовується класом FileSystem для роботи з файлами ресурсів.

### fileSystem
Глобальний екземпляр класу FileSystem.

#### Призначення
Надає глобальний доступ до файлової системи GZDoom з будь-якої частини коду.

#### Зв'язки з іншими модулями
Використовується багатьма модулями для доступу до ресурсів гри.

## Реалізація
Файл не містить власної реалізації, а лише імпортує класи з `fs_filesystem.h` та створює глобальний екземпляр класу FileSystem.
