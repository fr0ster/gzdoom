# d_buttons.h

**Призначення:**
- Описує структури та інтерфейси для роботи з кнопками (тригерами) на рівнях.

**Основні елементи:**
- Оголошення структур для зберігання стану кнопок.
- Функції для ініціалізації, оновлення, обробки натискань.

**Роль:**
- Дозволяє реалізувати інтерактивні елементи на рівнях (двері, перемикачі, тощо).
