# s_sndseq.cpp

**Призначення:**
- Реалізація системи послідовностей звуків (sound sequences): скриптовані звукові ефекти для рівнів, дверей, платформ тощо.

**Основні функції:**
- Відтворення, керування, зупинка звукових послідовностей.

**Роль:**
- Дозволяє створювати складні звукові сценарії для інтерактивних об'єктів.
