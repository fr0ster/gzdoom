# sound/

**Призначення папки:**
- Містить файли для роботи з аудіо: музика, звукові ефекти, мікшування, послідовності звуків.

**Основні файли:**
- `s_advsound.cpp` — розширені аудіо-можливості, підтримка сучасних бекендів.
- `s_doomsound.cpp/.h` — класичний звук Doom, базова реалізація звукової системи.
- `s_sndseq.cpp/.h` — система послідовностей звуків (sound sequences).
- `s_sound.h` — основні інтерфейси для роботи зі звуком.

**Роль:**
- Забезпечує відтворення музики, звуків, керування аудіо-ефектами у рушії.
