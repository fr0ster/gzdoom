# s_doomsound.cpp

**Призначення:**
- Базова реалізація звукової системи Doom: відтворення класичних звуків, підтримка оригінальних форматів.

**Основні функції:**
- Відтворення звуків, ініціалізація класичної аудіо-системи, керування каналами.

**Роль:**
- Забезпечує сумісність з класичними WAD-файлами та звуками Doom.
