# s_sound.h

**Призначення:**
- Описує основні інтерфейси для роботи зі звуком у рушії: відтворення, завантаження, керування каналами, ефекти.

**Основні елементи:**
- Оголошення функцій для роботи з аудіо, структури для опису звуків, каналів, ефектів.

**Роль:**
- Є основним інтерфейсом для всієї аудіо-системи рушія.
