# s_sndseq.h

**Призначення:**
- Описує інтерфейси для роботи з послідовностями звуків (sound sequences).

**Основні елементи:**
- Оголошення функцій для запуску, зупинки, керування звуковими послідовностями.

**Роль:**
- Дозволяє іншим модулям використовувати звукові сценарії для інтерактивних об'єктів.
