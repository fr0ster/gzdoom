# AActor (actor.h)

**Призначення:**
- Базовий клас для всіх об'єктів світу: гравці, монстри, предмети, декорації.

**Основні поля та методи:**
- `Pos()` — позиція у світі.
- `Angles` — напрямок.
- `Sector` — сектор мапи.
- Методи взаємодії, руху, обробки подій.

**Роль:**
- Є основою для всіх динамічних об'єктів у грі, використовується для логіки, рендерингу, AI.
