# gameconfigfile.cpp

**Призначення:**
- Реалізація зчитування, збереження та обробки конфігураційних файлів гри.

**Основні функції:**
- Зчитування налаштувань користувача, збереження змін, застосування параметрів до рушія.

**Роль:**
- Дозволяє користувачам налаштовувати гру через конфігураційні файли.
