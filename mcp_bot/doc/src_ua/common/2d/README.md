# README.md — common/2d/

**Папка:** `src/common/2d/`

**Призначення:**

Містить модулі для низькорівневого пристрій-незалежного 2D-рендерингу у рушії GZDoom. Забезпечує універсальний API для малювання текстур, полігонів, тексту, UI-елементів, HUD, statusbar, меню, cutscenes, з підтримкою трансформацій, скейлінгу, overlay, стінсилів, палітр, blend-стилів.

## Основні файли
- `v_2ddrawer.h/.cpp` — головний 2D-драйвер, API для рендерингу примітивів, полігонів, текстур, overlay, стінсилів, трансформацій.
- `v_draw.h/.cpp` — низькорівневі функції для координатних перетворень, UI-скейлінгу, малювання простих примітивів.
- `v_drawtext.h/.cpp` — малювання тексту, підтримка шрифтів, кольорів, ефектів, UI-скейлінгу.
- `wipe.h/.cpp` — ефекти переходу (wipe) для екрана.

## Призначення
- Єдиний універсальний шар для всіх 2D-операцій у рушії: HUD, меню, статусбар, консоль, cutscenes, текст, UI.
- Підтримка різних режимів масштабування, aspect ratio, overlay, палітр, blend-стилів, Canvas-текстур.
