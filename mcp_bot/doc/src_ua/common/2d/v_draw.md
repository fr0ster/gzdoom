# v_draw.h / v_draw.cpp

**Призначення:**

Модуль `v_draw` відповідає за низькорівневі операції з 2D-графікою: масштабування, координатні перетворення, малювання простих примітивів, підтримку UI-скейлінгу, допоміжні функції для рендерингу тексту, спрайтів, елементів інтерфейсу.

## Основні функції та об'єкти

- **VirtualToRealCoords** — перетворення координат з "віртуальних" (UI/логічних) у реальні піксельні (екранні), враховуючи масштабування, aspect ratio, UI-скейлінг.
- **GetUIScale** — визначає коефіцієнт масштабування для UI.
- **DrawChar, DrawText, DrawTextCommon** — малювання символів та рядків тексту з урахуванням кольору, шрифтів, позиції, ефектів (див. також v_drawtext.cpp).
- **Draw2D** — основна точка входу для рендерингу 2D-елементів через F2DDrawer.

## Інтерфейс
- Функції для малювання тексту, спрайтів, прямокутників, ліній, пікселів, з урахуванням трансформацій, скейлінгу, aspect ratio.
- Підтримка різних режимів масштабування (classic, auto-aspect, fullscreen, тощо).

## Місця використання
- Викликається з підсистем HUD, меню, statusbar, консолі, cutscenes, для малювання тексту, елементів UI, спрайтів.
- Тісно інтегрований з F2DDrawer (див. v_2ddrawer).

## Призначення та архітектура
- **Архітектура:**
  - Забезпечує універсальний API для малювання 2D-графіки з урахуванням різних режимів масштабування та aspect ratio.
  - Всі координатні перетворення централізовані для коректного відображення UI на різних роздільних здатностях.
- **Призначення:**
  - Базовий шар для всіх 2D-операцій у рушії, забезпечує коректне відображення інтерфейсу, тексту, HUD, меню, тощо.
