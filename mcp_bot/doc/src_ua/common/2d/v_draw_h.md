# v_draw_h.md

**Призначення:**

Заголовочний файл для модуля низькорівневого 2D-рендерингу та координатних перетворень у рушії GZDoom. Описує функції для малювання тексту, спрайтів, прямокутників, ліній, пікселів, а також для роботи з UI-скейлінгом, aspect ratio, трансформаціями.

## Основні функції
- `VirtualToRealCoords` — перетворення координат з логічних у екранні.
- `GetUIScale` — визначення коефіцієнта масштабування для UI.
- `DrawChar`, `DrawText`, `DrawTextCommon` — малювання символів та рядків тексту.
- Інші функції для малювання простих примітивів, прямокутників, ліній, пікселів.

## Місця використання
- Викликається з підсистем HUD, меню, statusbar, консолі, cutscenes, для малювання тексту, елементів UI, спрайтів.
- Тісно інтегрований з F2DDrawer (див. v_2ddrawer).
