# v_drawtext_h.md

**Призначення:**

Заголовочний файл для модуля рендерингу тексту у 2D-інтерфейсі рушія GZDoom. Описує функції для малювання символів, рядків, підтримки кольорів, шрифтів, позиціонування, UI-скейлінгу, трансформацій.

## Основні функції
- `DrawChar(F2DDrawer*, FFont*, ...)` — малювання символу.
- `DrawText(F2DDrawer*, FFont*, ...)` — малювання рядка тексту.
- `DrawTextCommon` — спільна логіка для тексту.

## Місця використання
- HUD, меню, statusbar, консоль, cutscenes, для відображення тексту.
- Використовує F2DDrawer для рендерингу.
