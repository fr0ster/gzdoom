# v_drawtext.cpp / v_drawtext.h

**Призначення:**

Модуль для рендерингу тексту у 2D-інтерфейсі рушія GZDoom. Забезпечує малювання символів, рядків, підтримку кольорів, шрифтів, позиціонування, ефектів, UI-скейлінгу, трансформацій.

## Основні функції
- `DrawChar(F2DDrawer*, FFont*, ...)` — малювання окремого символу з урахуванням кольору, позиції, шрифту.
- `DrawText(F2DDrawer*, FFont*, ...)` — малювання рядка тексту (різні перевантаження для char*, char32_t*, FString).
- `DrawTextCommon` — спільна логіка для малювання тексту з різними параметрами.

## Інтерфейс
- Параметри: шрифт, колір, позиція, рядок, додаткові ефекти (тіні, outline, alpha, тощо).
- Підтримка різних типів рядків (char*, char32_t*, FString).
- Підтримка UI-скейлінгу, aspect ratio, трансформацій.

## Місця використання
- Викликається з HUD, меню, statusbar, консолі, cutscenes, для відображення тексту.
- Використовує F2DDrawer для рендерингу.

## Призначення та архітектура
- **Архітектура:**
  - Всі текстові операції централізовані для коректного відображення на різних роздільних здатностях та UI-скейлах.
- **Призначення:**
  - Єдиний API для малювання тексту у рушії, підтримка кольорів, шрифтів, ефектів, трансформацій.
