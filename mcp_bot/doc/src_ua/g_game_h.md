# g_game.h

**Призначення:**
- Описує інтерфейси та структури для ігрової логіки: керування станом гри, гравцями, рівнями, AI.

**Основні елементи:**
- Оголошення функцій для оновлення стану, обробки подій, старту/завантаження рівнів.
- Структури для опису стану гри, гравців.

**Роль:**
- Забезпечує інтерфейс для основної ігрової логіки рушія.
