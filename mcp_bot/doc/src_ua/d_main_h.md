# d_main.h

**Призначення:**
- Описує інтерфейси для основних функцій запуску, ініціалізації, головного циклу рушія.

**Основні елементи:**
- Оголошення функцій: `D_DoomMain`, `D_InitGame`, `D_DoomLoop`, `D_ProcessEvents`.
- Глобальні змінні та константи для старту рушія.

**Роль:**
- Забезпечує інтерфейс для запуску та координації основних модулів.
