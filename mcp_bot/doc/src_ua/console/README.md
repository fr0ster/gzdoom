# console/

**Призначення папки:**
- Містить файли для реалізації ігрової консолі: команди, функції, буфер повідомлень.

**Основні файли:**
- `c_cmds.cpp` — реалізація консольних команд.
- `c_functions.cpp/.h` — реалізація та оголошення функцій для консолі.
- `c_notifybuffer.cpp` — буфер повідомлень консолі.

**Роль:**
- Дозволяє користувачу взаємодіяти з рушієм через консоль, виконувати команди, отримувати повідомлення.
