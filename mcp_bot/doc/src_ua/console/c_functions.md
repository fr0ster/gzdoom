# c_functions.cpp

**Призначення:**
- Реалізація функцій, які використовуються у консолі: математичні, утилітарні, робота з текстом, змінними.

**Основні функції:**
- Виконання функцій, які можна викликати з консолі.

**Роль:**
- Розширює можливості консолі, дозволяє виконувати складні операції через команди.
