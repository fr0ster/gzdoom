# events.cpp

**Призначення:**
- Реалізація обробки подій (input, системні, мережеві) у рушії.

**Основні функції:**
- Додавання, отримання, обробка подій з черги.
- Взаємодія з input-модулями, передача подій у Game Logic.

**Роль:**
- Забезпечує асинхронну обробку подій для всіх основних підсистем.
