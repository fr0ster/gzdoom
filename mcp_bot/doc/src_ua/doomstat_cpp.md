# doomstat.cpp

**Призначення:**
- Реалізація глобальних змінних і функцій для відстеження стану гри, статистики, параметрів рівня.

**Основні елементи:**
- Глобальні змінні для стану гри, статистики, параметрів поточного рівня.
- Функції для ініціалізації та оновлення статистики.

**Роль:**
- Дозволяє зберігати і оновлювати глобальний стан рушія під час гри.
