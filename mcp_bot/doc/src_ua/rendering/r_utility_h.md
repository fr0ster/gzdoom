# r_utility.h

**Призначення:**
- Описує інтерфейси для допоміжних функцій рендерингу: математика, обробка текстур, оптимізації.

**Основні елементи:**
- Оголошення функцій для підтримки рендерера, роботи з текстурами, оптимізації.

**Роль:**
- Дозволяє іншим модулям використовувати утиліти для рендерингу.
