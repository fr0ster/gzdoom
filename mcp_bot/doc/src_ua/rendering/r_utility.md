# r_utility.cpp

**Призначення:**
- Реалізація допоміжних функцій для рендерингу: математика, обробка текстур, оптимізації.

**Основні функції:**
- Математичні операції, робота з текстурами, оптимізація рендерингу.

**Роль:**
- Підтримує основний рендерер, забезпечує ефективність і розширюваність графічної підсистеми.
