# rendering/

**Призначення папки:**
- Містить файли для рендерингу: 2D/3D графіка, бекенди рендерингу, утиліти, небо, освітлення.

**Основні файли:**
- `r_sky.cpp/.h` — рендеринг неба, ефекти неба.
- `r_utility.cpp/.h` — допоміжні функції для рендерингу.
- `2d/`, `hwrenderer/`, `swrenderer/` — підпапки з реалізаціями різних рендер-бекендів.

**Роль:**
- Забезпечує побудову кадру, рендеринг 2D/3D графіки, ефекти, підтримку різних платформ.
