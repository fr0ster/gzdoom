# doomdef.h

**Призначення:**
- Внутрішні глобальні визначення, константи, структури, enum для рушія GZDoom.
- Описує режими гри, глобальні параметри, флаги deathmatch/coop, сумісності, багфікси, фізику, клавіші, константи для ігрової логіки.

## Основні структури та enum
- `GameMode_t` — режими гри: shareware, registered, commercial, retail, undetermined.
- `skill_t` — тип складності (float).
- `enum` для флагів deathmatch (DF_*), coop (DF2_*, DF3_*), сумісності (COMPATF_*, COMPATF2_*, BCOMPATF_*).
- Глобальні константи: `TICRATE`, `TELEFRAG_DAMAGE`, `TELEFOGHEIGHT`, параметри friction, BLINKTHRESHOLD.

## Основні флаги
- **Deathmatch/coop:** DF_*, DF2_*, DF3_* — контроль предметів, зброї, поведінки гравців, монстрів, інвентаря, respawn, ammo, тощо.
- **Сумісність:** COMPATF_*, COMPATF2_*, BCOMPATF_* — перемикачі для емуляції старих багів, особливостей різних версій Doom/Hexen/Strife.

## Інтерфейс
- Всі глобальні флаги доступні для ігрової логіки, налаштувань, скриптів, CVar.
- Включає keydef.h для визначення скан-кодів клавіш.

## Місця використання
- Використовується у всіх основних модулях рушія: логіка гри, input, physics, rendering, scripting, netcode, меню, HUD, statusbar, ZScript.
- Всі глобальні флаги та константи використовуються для налаштування ігрового процесу, сумісності, фізики, input.
