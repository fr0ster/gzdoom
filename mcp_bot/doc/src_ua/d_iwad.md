# d_iwad.cpp

**Призначення:**
- Логіка пошуку, вибору та завантаження основних WAD-файлів (IWAD) для запуску гри.

**Основні функції:**
- Визначення, які IWAD-файли доступні.
- Вибір IWAD для запуску гри.
- Перевірка цілісності та сумісності WAD-файлів.

**Роль:**
- Забезпечує коректний старт рушія з потрібними ігровими ресурсами.
