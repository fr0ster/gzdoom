# g_levellocals.h

**Призначення:**
- Описує структуру `FLevelLocals`, яка містить дані про поточний рівень: масив гравців, ітератор по акторам, параметри мапи, стан тригерів тощо.

**Основні структури:**
- `struct FLevelLocals` — основний контейнер для даних рівня.

**Роль:**
- Забезпечує доступ до всіх сутностей і параметрів поточного рівня для інших модулів рушія.
