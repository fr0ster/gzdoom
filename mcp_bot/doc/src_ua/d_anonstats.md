# d_anonstats.cpp

**Призначення:**
- Реалізація збору та обробки анонімної статистики під час гри.

**Основні функції:**
- Збір даних про ігрові сесії, події, параметри гравця.
- Відправка або збереження статистики для подальшого аналізу.

**Роль:**
- Дозволяє розробникам отримувати статистику використання гри без ідентифікації гравця.
