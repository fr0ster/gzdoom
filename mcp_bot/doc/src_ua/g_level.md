# g_level.cpp

**Призначення:**
- Реалізація логіки рівня: завантаження, ініціалізація, оновлення стану, обробка тригерів, керування об'єктами на рівні.

**Основні функції:**
- Завантаження та ініціалізація рівня.
- Оновлення стану об'єктів, обробка подій на рівні.
- Робота з секторами, BSP, тригерами.

**Роль:**
- Відповідає за життєвий цикл рівня, взаємодію об'єктів, логіку проходження.
