# doomstat.h

**Призначення:**
- Містить глобальні змінні та структури для відстеження стану гри, статистики, параметрів рівня.

**Основні елементи:**
- Глобальні змінні для стану гри, статистики, параметрів поточного рівня.

**Роль:**
- Використовується для зберігання і доступу до глобального стану рушія.
