# gamedata/

**Призначення папки:**
- Містить файли, пов'язані з ігровими даними: зброя, ключі, типи ігор, інформація про карти, декалі, шрифти, параметри складності, текстури, переклади, тощо.

**Основні файли:**
- `a_keys.cpp/.h` — логіка ключів (keycards, skulls).
- `a_weapons.cpp/.h` — логіка зброї.
- `g_mapinfo.cpp/.h` — інформація про карти, параметри рівнів.
- `g_skill.cpp` — параметри складності.
- `decallib.cpp/.h` — бібліотека декалей (blood, сліди).
- `info.cpp/.h` — інформація про об'єкти, типи, властивості.
- `teaminfo.cpp/.h` — інформація про команди у мультиплеєрі.
- `textures/` — підпапка з описом текстур.
- `xlat/` — підпапка з перекладами/трансляціями.

**Роль:**
- Забезпечує зберігання, завантаження та обробку ігрових даних, які використовуються рушієм.
