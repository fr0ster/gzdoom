# a_weapons.cpp

**Призначення:**
- Реалізація логіки зброї: атаки, перезарядка, перемикання, взаємодія з гравцем та ворогами.

**Основні функції:**
- Оновлення стану зброї, виконання атак, зміна зброї, взаємодія з інвентарем.

**Роль:**
- Дозволяє реалізувати різноманітну зброю та її поведінку у грі.
