# info.cpp

**Призначення:**
- Реалізація зчитування та обробки інформації про об'єкти, їхні властивості, типи, поведінку.

**Основні функції:**
- Завантаження, зберігання, доступ до інформації про об'єкти (монстри, предмети, декорації).

**Роль:**
- Дозволяє рушію працювати з різними типами об'єктів, їхніми властивостями та поведінкою.
