# g_mapinfo.cpp

**Призначення:**
- Реалізація завантаження та обробки інформації про карти (MAPINFO): параметри рівнів, властивості, сценарії.

**Основні функції:**
- Зчитування, зберігання, застосування параметрів рівнів.

**Роль:**
- Дозволяє налаштовувати поведінку, вигляд, правила для кожного рівня.
