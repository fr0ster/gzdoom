# g_hub.h

**Призначення:**
- Описує інтерфейси та структури для роботи з "хабами" (рівнями-зв'язками).

**Основні елементи:**
- Оголошення функцій для збереження/відновлення стану, переходу між рівнями.
- Структури для зберігання інформації про хаби.

**Роль:**
- Забезпечує інтерфейс для організації нелінійних кампаній з переходами між рівнями.
