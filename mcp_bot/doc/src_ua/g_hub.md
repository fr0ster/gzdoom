# g_hub.cpp

**Призначення:**
- Реалізація логіки "хабів" — спеціальних рівнів, які з'єднують інші рівні (наприклад, для нелінійних кампаній).

**Основні функції:**
- Збереження/відновлення стану між рівнями.
- Перехід між рівнями, збереження інвентарю, стану гравців.

**Роль:**
- Дозволяє створювати складні структури кампаній з поверненням на попередні рівні та збереженням прогресу.
