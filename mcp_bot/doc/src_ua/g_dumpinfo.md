# g_dumpinfo.cpp

**Призначення:**
- Реалізація функцій для виводу (дампу) інформації про стан гри, рівня, об'єктів для налагодження.

**Основні функції:**
- Вивід інформації про гравців, акторів, параметри рівня, ресурси.

**Роль:**
- Допомагає розробникам і моддерам аналізувати стан рушія під час виконання.
