# player_t (d_player.h)

**Призначення:**
- Структура, що описує стан гравця: позиція, здоров'я, інвентар, камера, поточна зброя, параметри руху тощо.

**Основні поля:**
- `mo` — вказівник на AActor, що представляє гравця у світі.
- `camera` — камера гравця.
- `health`, `inventory`, `weapon`, `viewz`, `Vel`, `Angles` — основні параметри стану.

**Роль:**
- Зберігає ігровий стан гравця для логіки, рендерингу, AI.
