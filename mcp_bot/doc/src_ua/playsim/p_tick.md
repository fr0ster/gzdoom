# p_tick.cpp

**Призначення:**
- Реалізація основного "тику" (ітерації) ігрової симуляції: оновлення стану всіх об'єктів, AI, фізики, тригерів.

**Основні функції:**
- Оновлення всіх "думаючих" об'єктів (DThinker), акторів, гравців, спеціальних ефектів.

**Роль:**
- Є основою для циклічного оновлення ігрового світу, забезпечує динаміку та взаємодію.
