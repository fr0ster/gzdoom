# p_map.cpp

**Призначення:**
- Реалізація логіки карти: розміщення об'єктів, оновлення стану секторів, взаємодія з тригерами, портали, BSP.

**Основні функції:**
- Оновлення стану карти, обробка подій, взаємодія з актороми, порталами, тригерами.

**Роль:**
- Відповідає за динаміку карти, взаємодію об'єктів, просторову логіку.
