# d_player.h

**Призначення:**
- Описує структуру гравця (`player_t`): позиція, стан, камера, інвентар, зброя, параметри руху.

**Основні елементи:**
- Оголошення структури `player_t` та її основних полів.
- Методи для оновлення стану гравця, взаємодії з актором, інвентарем, зброєю.

**Роль:**
- Зберігає ігровий стан гравця для логіки, рендерингу, AI.
