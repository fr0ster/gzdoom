# p_enemy.cpp

**Призначення:**
- Реалізація логіки ворогів: поведінка, AI, атаки, пересування, взаємодія з гравцем.

**Основні функції:**
- Оновлення стану ворогів, виконання AI, обробка подій, атаки, переміщення.

**Роль:**
- Відповідає за поведінку ворогів, їхню взаємодію з гравцем та іншими об'єктами.
