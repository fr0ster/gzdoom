# portal.h

**Призначення:**
- Описує структури та інтерфейси для роботи з порталами (з'єднання різних частин карти, просторові переходи).

**Основні елементи:**
- Оголошення класів/структур для опису порталів.
- Методи для створення, оновлення, взаємодії з порталами.

**Роль:**
- Дозволяє реалізувати складні просторові ефекти, переходи між частинами карти.
