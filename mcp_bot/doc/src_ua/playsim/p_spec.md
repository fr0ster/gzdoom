# p_spec.cpp

**Призначення:**
- Реалізація спеціальних ефектів і тригерів на рівнях (ліфти, двері, платформи, пастки тощо).

**Основні функції:**
- Оновлення стану спеціальних об'єктів, обробка активації тригерів, взаємодія з гравцем та акторами.

**Роль:**
- Дозволяє створювати інтерактивні елементи та динаміку на рівнях.
