# actor.h

**Призначення:**
- Базовий клас для всіх динамічних об'єктів у світі (AActor): гравці, монстри, предмети, декорації.

**Основні елементи:**
- Оголошення класу `AActor` та його основних полів/методів.
- Визначення взаємодії, руху, стану, подій для акторів.

**Роль:**
- Є основою для всієї ігрової логіки, AI, рендерингу, фізики.
