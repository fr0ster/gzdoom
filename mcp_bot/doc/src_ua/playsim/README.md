# playsim/

**Призначення папки:**
- Містить основні файли ігрової симуляції: логіка акторів, гравців, фізика, AI, тригери, спеціальні ефекти, портали, тощо.

**Основні файли:**
- `actor.h` — базовий клас для всіх об'єктів світу (AActor).
- `d_player.h` — структура гравця (player_t).
- `dthinker.h` — базовий клас для об'єктів, що "думають" (логіка, AI).
- `portal.h` — логіка порталів.
- `p_map.cpp` — логіка карти, розміщення об'єктів.
- `p_enemy.cpp` — логіка ворогів.
- ...та інші (див. окремі markdown-файли для кожного).

**Роль:**
- Відповідає за симуляцію ігрового світу, взаємодію об'єктів, AI, фізику, спеціальні ефекти.
