# dthinker.h

**Призначення:**
- Описує базовий клас для "думаючих" об'єктів (логіка, AI, таймери, тригери).

**Основні елементи:**
- Оголошення класу `DThinker` та його похідних.
- Методи для оновлення стану, виконання логіки, взаємодії з іншими об'єктами.

**Роль:**
- Є основою для AI, таймерів, тригерів, спеціальних ефектів у грі.
