# g_game.cpp

**Призначення:**
- Основна логіка гри: керування станом гри, гравцями, рівнями, AI, фізикою.

**Основні функції:**
- `void G_Ticker();` — оновлення стану світу, виклик AI, фізики, тригерів.
- `bool G_Responder(event_t* ev);` — обробка подій (input).
- Інші функції для старту/завантаження рівнів, керування гравцями, збереження/завантаження гри.

**Роль:**
- Відповідає за ігровий цикл, логіку рівнів, взаємодію гравців та акторів.
