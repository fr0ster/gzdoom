# d_defcvars.cpp

**Призначення:**
- Реалізація та ініціалізація консольних змінних (CVARs) рушія.

**Основні функції:**
- Оголошення та реєстрація змінних, які можна змінювати через консоль або конфігураційні файли.

**Роль:**
- Дозволяє налаштовувати параметри гри, рушія, рендерингу, аудіо тощо під час виконання.
