# d_net.cpp

**Призначення:**
- Реалізація мережевої взаємодії: синхронізація стану гри, передача подій, підтримка мультиплеєра.

**Основні функції:**
- Ініціалізація мережі, обробка пакетів, синхронізація гравців.

**Роль:**
- Дозволяє запускати гру у мережевому режимі, підтримує мультиплеєрні функції.
